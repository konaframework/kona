# hello-kotlin

Kona application (Kotlin) — complete Almasix-shaped tree under `src/main`.

## Layout

- `src/main/kotlin/bootstrap` — `App` + `Middleware` (session + CSRF)
- `src/main/kotlin/app` — providers, HTTP, models
- `src/main/kotlin/routes` — web + api
- `src/main/resources/config` — JSON config (`app`, `http`, `paths`, `session`)
- `storage/` — writable runtime data
- `.env.example` — environment template (`APP_KEY` generated by `kona new`)

Path helpers: `app.appPath()`, `app.storagePath()`, `Paths.config()`, …

## Commands

From the Kona repo root (composite build):

```bash
./gradlew :hello-kotlin:run
./gradlew :hello-kotlin:test
```

Or scaffold a standalone copy with `kona new` and use `./grind serve`.
