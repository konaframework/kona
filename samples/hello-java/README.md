# hello-java

Kona application (Java) — complete Almasix-shaped tree under `src/main`.

## Layout

- `src/main/java/bootstrap` — `App` + `Middleware` (session + CSRF)
- `src/main/java/app` — providers, HTTP, models
- `src/main/java/routes` — web + api
- `src/main/resources/config` — JSON config (`app`, `http`, `paths`, `session`)
- `storage/` — writable runtime data
- `.env.example` — environment template (`APP_KEY` generated by `kona new`)

## Commands

From the Kona repo root (composite build):

```bash
./gradlew :hello-java:run
./gradlew :hello-java:test
```

Or scaffold a standalone copy with `kona new --lang=java` and use `./grind serve`.
