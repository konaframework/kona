---
title: External redirects
description: Inertia.location for cross-origin or hard navigations.
---

```kotlin
Inertia.location("https://example.com")
```

| Client | Status | Headers |
|--------|--------|---------|
| Inertia (`X-Inertia` + current request set) | `409` | `X-Inertia-Location: <url>` |
| Ordinary browser / no Inertia request | `302` | `Location: <url>` |

Requires a current request on the manager for the Inertia branch (middleware). Without a current request, behavior is the ordinary `302`.

After middleware, `decorate` may add `X-Inertia-Version` when the response already carries `X-Inertia-Location`.
