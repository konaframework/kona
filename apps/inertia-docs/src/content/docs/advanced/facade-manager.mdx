## InertiaManager

Owns:

- `version`, `rootView`, `rootHtml`, `cremaEngine`, `viteEntries`
- Global `sharedProps` (`ConcurrentHashMap`)
- ThreadLocal current `Request` and per-request shared map
- `render` / `location` / `versionConflict` / `decorate` / `isInertiaRequest`

## Facade

`Inertia` is a process-wide holder for the active manager. `InertiaServiceProvider.boot` calls `Inertia.setManager`. Tests should call `Inertia.reset()` (and `Vite.reset()`) in `@AfterEach`.

## HtmlAttr

`HtmlAttr.escape` escapes `& < > " '` for embedding JSON in HTML attributes (`pageAttr` / `@page`).
