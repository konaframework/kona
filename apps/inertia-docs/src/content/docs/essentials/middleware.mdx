`HandleInertiaRequests` (typealias `InertiaMiddleware`) should sit on the HTTP kernel for all Inertia routes.

## Lifecycle

1. Resolve `Inertia.manager()` (requires booted `InertiaServiceProvider`)
2. `setRequest(request)`
3. Apply `share(request)` → `shareForRequest`
4. Optional `version(request)` → updates `manager.version`
5. If `versionConflict(request)` → return decorated `409`
6. Else `decorate(next.handle(request))`
7. `finally` → `setRequest(null)` (clears request-scoped shared props)

## Overrides

| Method | Default | Purpose |
|--------|---------|---------|
| `share(request)` | empty map | Per-request props |
| `version(request)` | `null` (keep manager version) | Dynamic asset version |

## Registration

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.resolve(HttpKernel::class.java).pushMiddleware(HandleInertia())
// or alias via HttpMiddleware if you use the web stack
```

</TabItem>
<TabItem label="Java">

```java
app.resolve(HttpKernel.class).pushMiddleware(new HandleInertia());
```

</TabItem>
</Tabs>

Push **after** `InertiaServiceProvider` has booted so the facade manager is set.
