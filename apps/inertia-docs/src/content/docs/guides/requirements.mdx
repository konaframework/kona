## Runtime

| Requirement | Notes |
|-------------|--------|
| **JDK 21+** | Virtual threads; same as Kona core |
| **Kona modules** | `kona-core`, `kona-http`, and usually `kona-crema` for the root view |
| **Maven local or Central** | Until Central publishes are live, publish Kona then `kona-inertia` to `~/.m2` |

## Frontend (your app)

Inertia itself does not bundle Vue/React/Svelte. Your app’s `package.json` should add an Inertia adapter (for example `@inertiajs/vue3`) and Vite. The Kona CLI **inertia** starter kit drops Vite stubs and a JS entry under `src/main/resources/js/app.js`.

## Docs site (this repository)

Building the documentation under `apps/docs/` needs **Node 22+**.

## Publish order (local)

```bash
# 1. Kona framework
(cd ../kona && ./gradlew publishToMavenLocal -x test)

# 2. This package
./gradlew :kona-inertia:publishToMavenLocal
```
