# Firefly screenshots

Drop a PNG in this folder and rebuild the docs site. The page that names the file shows the image, with the description as the alt text and the caption. If the file is not here, the page shows a placeholder with the filename, this folder (`apps/docs/public/images/firefly/`), and the description.

Files are served as `/images/firefly/<file>`.
