Every public entry point is `@JvmStatic` or an open Java class so Java apps call the same API.

## Facade (`Inertia`)

- `setManager` / `manager` / `reset`
- `render` (1–3 argument overloads)
- `share` (key/value and map)
- `version`
- `location`

## Middleware

Extend `HandleInertiaRequests` and override `share` / `version`. Return types use maps that Java can construct with `Map.of`.

## Samples

| Sample | Path |
|--------|------|
| Kotlin | `samples/inertia-kotlin` |
| Java | `samples/inertia-java` |

./gradlew :inertia-sample-kotlin:test :inertia-sample-java:test
