`ColorPicker` stores a color string. The UI is a swatch next to a text input. Format helpers set both the placeholder and the validation regex.

<FireflyShot file="form-color-picker.png" description="ColorPicker color field on the Playground form." />

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
ColorPicker.make("color")
    .label("Brand color")
    .hex()
    .required()
```

</TabItem>
<TabItem label="Java">

```java
ColorPicker.make("color")
    .label("Brand color")
    .hex()
    .required();
```

</TabItem>
</Tabs>

## Options

| Method | Effect |
|--------|--------|
| `hex()` | `#RRGGBB` (default) |
| `rgb()` | `rgb(r, g, b)` |
| `hsl()` | `hsl(h, s%, l%)` |
| `format()` | Current format name |
| `normalize(raw)` | Returns the string if it matches the format, else null |
