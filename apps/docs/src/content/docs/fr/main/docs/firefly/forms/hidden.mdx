`Hidden` renders a hidden HTML input and skips the visible label chrome. Use it for tokens, parent ids, or other state that must post with the form.

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val token = Hidden.make("token")
schema.fill(mapOf("token" to "abc123"))
```

</TabItem>
<TabItem label="Java">

```java
Hidden token = Hidden.make("token");
schema.fill(Map.of("token", "abc123"));
```

</TabItem>
</Tabs>

## Behavior

- `kind()` is `"hidden"`.
- The control is `<input type="hidden" …>` with the same Wire entanglement as other fields.
- Shared helpers (`rule`, `dehydrated` / `saved`, `formatStateUsing`, …) still apply; there is no type-specific API beyond `make` / `configureUsing`.
