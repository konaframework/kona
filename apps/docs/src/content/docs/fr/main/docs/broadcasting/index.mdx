**Broadcasting** pousse les événements de l’application vers des canaux nommés afin que les écouteurs (abonnés websocket dans le processus, tests, ou un futur pilote réseau) puissent réagir.

## Enregistrer

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.register(BroadcastServiceProvider())
```

Clés de config :

| Clé | Signification |
|-----|---------|
| `broadcasting.default` | Nom de connexion (défaut `log`) |
| `broadcasting.connections.{name}.driver` | `log`, `null` / `none`, ou `websocket` / `ws` |

## Événements ShouldBroadcast

```kotlin
class OrderShipped : ShouldBroadcast {
    override fun broadcastOn() = listOf(Channel.publicChannel("orders"))
    override fun broadcastAs() = "order.shipped"
    override fun broadcastWith() = mapOf("id" to 42)
}

Broadcast.event(OrderShipped())
```

</TabItem>
<TabItem label="Java">

```java
Broadcast.event(new OrderShipped());
```

</TabItem>
</Tabs>

## Diffusions ad hoc

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
Broadcast.to(Channel.publicChannel("orders"), Channel.privateOf("user.1"))
    .event("order.shipped", mapOf("id" to 42))
```

## Pilotes

| Pilote | Comportement |
|--------|----------|
| `log` | Stocke les charges en mémoire (`Broadcast.manager().log().messages()`) — idéal pour les tests |
| `null` / `none` | Sans effet |
| `websocket` / `ws` | Répartition dans le processus vers les handlers de connexion enregistrés (`WebsocketBroadcaster`) |

### Websocket (dans le processus)

`WebsocketBroadcaster` garde une map canal → écouteur. Abonnez-vous localement, puis diffusez ; chaque connexion distincte reçoit la charge une fois même si elle écoute plusieurs canaux correspondants. Il n’y a pas de socket réseau dans cette version — le pilote a la forme websocket (abonnement + répartition) pour les tests et les appelants Java, prêt à envelopper un endpoint Netty plus tard.

```kotlin
val ws = Broadcast.manager().websocket()
ws.subscribe("orders") { channels, event, payload ->
    // deliver to a client connection
}
app.config.set("broadcasting.default", "websocket")
Broadcast.event(OrderShipped())
```
