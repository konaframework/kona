---
title: Page d’accueil
description: Route minimale qui rend Pages/Welcome avec une prop message.
---

```kotlin
router.get("/") {
    Inertia.render(
        "Pages/Welcome",
        mapOf("message" to "Welcome to Kona Inertia"),
    )
}
```

```java
router.get("/", request ->
    Inertia.render("Pages/Welcome", Map.of("message", "Welcome to Kona Inertia"))
);
```

Première visite → HTML `data-page` contenant le nom du composant. Visite Inertia → JSON avec les mêmes props.
