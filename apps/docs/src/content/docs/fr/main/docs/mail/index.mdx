---
title: Mail
description: Envoyez des mailables via les transports log ou SMTP.
---

Construisez les messages avec `Mailable` / `MailMessage`, puis envoyez-les via un `Mailer`.

## Démarrage rapide

```kotlin
class WelcomeMail : Mailable() {
    override fun envelope() = Envelope(subject = "Welcome", from = Address("app@example.com"))
    override fun content() = Content(html = "<p>Hi</p>", text = "Hi")
}

app.resolve(Mailer::class.java).to("user@example.com").send(WelcomeMail())
```

Enregistrez `MailServiceProvider`. Pilotes :

| Transport | Configuration |
| --- | --- |
| `log` / `array` | Enregistre les messages (pratique pour les tests) |
| `smtp` | `host`, `port`, `username`, `password` |

Valeurs par défaut : `mail.default`, `mail.from.address`, `mail.from.name`.
