## 1. Rendre depuis une route

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
router.get("/") {
    Inertia.render(
        "Pages/Welcome",
        mapOf(
            "title" to "Hello",
            "message" to "First Inertia page",
        ),
    )
}
```

</TabItem>
<TabItem label="Java">

```java
router.get("/", request ->
    Inertia.render(
        "Pages/Welcome",
        Map.of(
            "title", "Hello",
            "message", "First Inertia page"
        )
    )
);
```

</TabItem>
</Tabs>

`Inertia.render` exige une requête courante (posée par `HandleInertiaRequests`) sauf si vous passez le `Request` explicitement. Consultez [Rendu](../../essentials/rendering/).

## 2. Première visite (HTML complet)

Le navigateur navigue vers `/` **sans** en-tête `X-Inertia`.

1. Le middleware pose la requête sur `InertiaManager`, fusionne les props partagées, vérifie la version (aucune au premier chargement de document).
2. Votre route renvoie une réponse Inertia.
3. Le manager construit un `InertiaPage` et rend la vue Crema racine (`inertia.root_view`) avec :
   - `pageAttr` — JSON échappé HTML de l’objet de page
   - `vite` — balises script/link pour l’entrée client
4. La réponse est `text/html`.

Inspectez `#app` :

```html
<div
  id="app"
  data-page="{&quot;component&quot;:&quot;Pages/Welcome&quot;,&quot;props&quot;:{&quot;title&quot;:&quot;Hello&quot;,…},&quot;url&quot;:&quot;/&quot;,&quot;version&quot;:&quot;1&quot;}"
></div>
```

L’entrée Vue/React/Svelte hydrate ce JSON dans `Pages/Welcome`.

## 3. Visite Inertia (JSON)

Une fois le client monté, un lien Inertia ou `router.visit` envoie :

```http
GET / HTTP/1.1
X-Inertia: true
X-Inertia-Version: 1
Accept: text/html, application/xhtml+xml
X-Requested-With: XMLHttpRequest
```

(Les en-têtes client exacts dépendent de l’adaptateur ; `X-Inertia: true` est requis pour le mode JSON.)

Comportement serveur :

1. L’en-tête de version correspond → continuer.
2. La route rend le même `Inertia.render(…)`.
3. Le corps de réponse est du JSON (pas la coquille Crema) :

```json
{
  "component": "Pages/Welcome",
  "props": { "title": "Hello", "message": "First Inertia page" },
  "url": "/",
  "version": "1"
}
```

Les en-têtes incluent `X-Inertia: true`, `Vary: X-Inertia` et `X-Inertia-Version` lorsqu’une version est configurée.

## 4. Conflit de version

Si le client envoie un `X-Inertia-Version` périmé, le middleware renvoie **409** afin que l’adaptateur force un rechargement complet et prenne les nouveaux assets. Configurez `inertia.version` (ou surchargez `version(request)` sur votre middleware). Consultez [Version des assets](../../advanced/versioning/).

## 5. Props partagées

Les messages flash, l’utilisateur auth et les URL de style ziggy appartiennent à `share(request)` du middleware ou à `Inertia.share(…)` — pas dans chaque contrôleur. Consultez [Données partagées](../../essentials/shared-data/).

## 6. Composant de page client

Faites correspondre le nom serveur. Exemple Vue (`js/Pages/Welcome.vue`) :

```vue
<script setup>
defineProps({ title: String, message: String });
</script>
<template>
  <h1>{{ title }}</h1>
  <p>{{ message }}</p>
</template>
```
