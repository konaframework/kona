Voici le hub de documentation de **Kona**. L’accueil marketing vit à la racine du site ; tout ce qui suit explique comment construire avec le framework.

Kona démarre une **application**, branche les fonctionnalités avec des **service providers**, résout les services depuis un **conteneur**, et répond en HTTP avec des **routes** et du **middleware**. Les mêmes API fonctionnent depuis Kotlin et Java. Le CLI **grind** échafaude et sert votre projet.

Suivez la barre latérale dans l’ordre si vous débutez : **Premiers pas** → **Les bases** → **Crema**, puis **Aller plus loin**, et bifurquez vers **Sécurité**, **Base de données**, **Frontend**, **Wire**, **Inertia**, **Firefly**, **Tests** et **Paquets et outillage** selon vos besoins.
