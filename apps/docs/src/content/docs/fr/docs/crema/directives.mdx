## Échos et commentaires

| Syntaxe | Rôle | Guide |
|--------|---------|-------|
| `{{ expr }}` | Sortie échappée | [Rendu](/docs/crema/rendering/) |
| `{!! expr !!}` | Sortie HTML brute | [Rendu](/docs/crema/rendering/) |
| `{{ url(path) }}` / `{{ route(name) }}` / `{{ asset(path) }}` | URL d’app / nommée / publique | [Rendu](/docs/crema/rendering/#echo-helpers) |
| `{{ csrf_token() }}` / `{{ old(key) }}` | Jeton CSRF / entrée flashée | [Rendu](/docs/crema/rendering/#echo-helpers) |
| `{{ env(key) }}` / `{{ config(key) }}` | Environnement / config | [Rendu](/docs/crema/rendering/#echo-helpers) |
| `{{ trans(key) }}` / `{{ __(key) }}` / `{{ lang(key) }}` | Traduction | [Rendu](/docs/crema/rendering/#echo-helpers) |
| `@@` | `@` littéral | [Rendu](/docs/crema/rendering/) |
| `{{-- … --}}` | Commentaire (retiré) | [Rendu](/docs/crema/rendering/) |

## Layouts et sections

| Directive | Fermeture / notes | Guide |
|-----------|----------------|-------|
| `@extends('layout')` | L’enfant déclare le layout parent | [Layouts](/docs/crema/layouts/) |
| `@section('name', 'text')` | Section inline | [Layouts](/docs/crema/layouts/) |
| `@section('name')` | Section en bloc | `@endsection` ou `@show` |
| `@endsection` | Fin de section en bloc (stocke brut) | [Layouts](/docs/crema/layouts/) |
| `@show` | Fin de section et expansion immédiate | [Layouts](/docs/crema/layouts/) |
| `@yield('name')` | Imprime la section | Défaut optionnel : `@yield('n', 'default')` |
| `@parent` | Insère le buffer de section parent | Dans un `@section` enfant |
| `@hasSection('name')` | Corps si la section est définie | Se ferme avec `@endif` |
| `@sectionMissing('name')` | Corps si la section manque | Se ferme avec `@endif` |

## Composants et slots

| Syntaxe | Rôle | Guide |
|--------|---------|-------|
| `@component('name')…@endcomponent` | Rend une vue comme composant | [Composants](/docs/crema/components/) |
| `@slot('name')…@endslot` | Slot nommé dans `@component` | [Composants](/docs/crema/components/) |
| `<x-name>…</x-name>` | Rend `components.name` | [Composants](/docs/crema/components/) |
| `<x-name />` | Slot par défaut vide | [Composants](/docs/crema/components/) |
| `<x-slot name="n">…</x-slot>` | Slot nommé pour `<x-*>` ou balises préfixées | [Composants](/docs/crema/components/) |
| `<x-slot:n>…</x-slot:n>` | Forme à nom deux-points | [Composants](/docs/crema/components/) |
| `<prefix:slot name="n">…` | Slot nommé pour les balises d’extension | [Composants](/docs/crema/components/) |

Dans la vue du composant : `{{ slot }}` (défaut) et `{{ name }}` pour chaque slot nommé.

## Extensions personnalisées

Les apps et les paquets peuvent enregistrer plus de syntaxe sur `CremaEngine` :

| API | Forme |
|-----|-------|
| `directive(name) { … }` | `@name` / `@name(args)` |
| `blockDirective(name) { … }` | `@name…@endname` |
| `tag(prefix) { … }` | `<prefix:name>…` |

Wire les utilise pour `@brew` et `<wire:…>`. Voir [Wire](/docs/wire/).
