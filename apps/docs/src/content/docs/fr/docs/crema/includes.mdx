---
title: Inclusions et partiels
description: Incluez des templates partiels, des blocs once et des régions verbatim dans Crema.
---

Les **partiels** sont des vues ordinaires destinées à être composées dans d’autres templates — navigation, bannières flash, extraits de champ de formulaire. Crema n’utilise pas un type de fichier « fragment » séparé : n’importe quel nom de vue peut être inclus. Les inclusions partagent les sections et les stacks du parent à travers un contexte de données enfant (les clés du parent restent visibles ; l’inclusion peut lire le même `name`, `user`, et ainsi de suite).

## Toujours inclure

```crema
@include('partials.nav')
```

Résout `src/main/resources/views/partials/nav.crema.html` (nom pointé → chemin). Les vues absentes lancent `ViewNotFoundException`.

```crema
{{-- views/partials/nav.crema.html --}}
<nav>
  <a href="/">Home</a>
  @auth
    <a href="/account">Account</a>
  @endauth
</nav>
```

## Inclusion optionnelle

```crema
@includeIf('optional.banner')
```

Ne rend rien quand le fichier de vue manque (pas d’erreur). Utilisez cela pour des surcharges de thème ou des paquets optionnels.

## Inclusion conditionnelle

```crema
@includeWhen(showBanner, 'partials.banner')
@includeUnless(hideBanner, 'partials.banner')
```

| Directive | Rend la vue quand… |
|-----------|------------------------|
| `@includeWhen(expr, 'name')` | `expr` est truthy |
| `@includeUnless(expr, 'name')` | `expr` n’est pas truthy |

## Première vue disponible

```crema
@includeFirst(['theme.banner', 'partials.banner'])
```

Rend le premier nom entre guillemets qui se résout ; saute les vues absentes sans erreur. Si aucune ne se résout, n’émet rien.

Utile pour des partiels « préférer le thème, retomber sur le défaut » :

```crema
@includeFirst([
  'themes.current.flash',
  'partials.flash',
])
```

## `@once`

```crema
@once
  <script>window.__konaFlash = true;</script>
@endonce
```

Le corps se rend au plus **une fois par passage de rendu**, même si le partiel qui le contient est inclus plusieurs fois. Les corps `@once` identiques partagent la même clé. Les stacks et les sections fonctionnent encore dans le corps au premier passage.

## `@verbatim`

```crema
@verbatim
  Document {{ this }} and @if(examples) literally.
@endverbatim
```

Rien dans `@verbatim`…`@endverbatim` n’est traité comme du Crema — les échos et les directives restent du texte. Utilisez cela dans les pages de documentation ou quand vous embarquez des exemples de template dans un layout Crema.

## Partiels, layouts et composants

| Approche | Quand l’utiliser |
|----------|-------------|
| `@include` | Petits morceaux partagés (nav, champ, bandeau d’alerte) |
| `@extends` / `@section` | Coquilles de page complète avec des régions nommées — [Layouts](/docs/crema/layouts/) |
| `@component` / `<x-*>` | Widgets réutilisables avec un slot par défaut et des **slots nommés** optionnels — [Composants](/docs/crema/components/) |

Les inclusions n’isolent pas les stacks : un `@push('scripts')` dans un partiel atterrit quand même sur le `@stack('scripts')` du layout.
