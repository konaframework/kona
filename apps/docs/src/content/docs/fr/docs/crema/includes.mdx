---
title: Includes et partiels
description: Incluez des modèles partiels, des blocs once et des régions verbatim dans Crema.
---

Les **partiels** sont des vues ordinaires destinées à être composées dans d’autres modèles — navigation, bannières flash, extraits de champ de formulaire. Crema n’utilise pas un type de fichier « fragment » séparé : n’importe quel nom de vue peut être inclus. Les includes partagent les sections et les piles du parent à travers un contexte de données enfant (les clés parentes restent visibles ; l’include peut lire le même `name`, `user`, et ainsi de suite).

## Inclure toujours

```crema
@include('partials.nav')
```

Résout `src/main/resources/views/partials/nav.crema.html` (nom pointé → chemin). Les vues manquantes lancent `ViewNotFoundException`.

```crema
{{-- views/partials/nav.crema.html --}}
<nav>
  <a href="/">Home</a>
  @auth
    <a href="/account">Account</a>
  @endauth
</nav>
```

## Include optionnel

```crema
@includeIf('optional.banner')
```

Ne rend rien lorsque le fichier de vue est absent (pas d’erreur). Utilisez ceci pour les surcharges de thème ou les paquets optionnels.

## Include conditionnel

```crema
@includeWhen(showBanner, 'partials.banner')
@includeUnless(hideBanner, 'partials.banner')
```

| Directive | Rend la vue lorsque… |
|-----------|------------------------|
| `@includeWhen(expr, 'name')` | `expr` est vrai |
| `@includeUnless(expr, 'name')` | `expr` n’est pas vrai |

## Première vue disponible

```crema
@includeFirst(['theme.banner', 'partials.banner'])
```

Rend le premier nom cité qui se résout ; ignore les vues manquantes sans erreur. Si aucun ne se résout, n’émet rien.

Utile pour des partiels « préférer le thème, retomber sur le défaut » :

```crema
@includeFirst([
  'themes.current.flash',
  'partials.flash',
])
```

## `@once`

```crema
@once
  <script>window.__konaFlash = true;</script>
@endonce
```

Le corps se rend au plus **une fois par passe de rendu**, même si le partiel qui le contient est inclus plusieurs fois. Les corps `@once` identiques partagent la même clé. Les piles et les sections fonctionnent encore dans le corps lors de la première passe.

## `@verbatim`

```crema
@verbatim
  Document {{ this }} and @if(examples) literally.
@endverbatim
```

Rien à l’intérieur de `@verbatim`…`@endverbatim` n’est traité comme Crema — les échos et les directives restent du texte. Utilisez ceci dans les pages de documentation ou lorsque vous embarquez des exemples de modèle dans un layout Crema.

## Partiels, layouts et composants

| Approche | Quand l’utiliser |
|----------|-------------|
| `@include` | Petits morceaux partagés (nav, champ, bandeau d’alerte) |
| `@extends` / `@section` | Coquilles de page complète avec régions nommées — [Layouts](/docs/crema/layouts/) |
| `@component` / `<x-*>` | Widgets réutilisables avec un slot par défaut et des **slots nommés** optionnels — [Composants](/docs/crema/components/) |

Les includes n’isolent pas les piles : un `@push('scripts')` dans un partiel arrive quand même sur le `@stack('scripts')` du layout.
