---
title: Conflit de version
description: Forcez un 409 lorsque la version des assets du client est périmée.
---

```kotlin
Inertia.version("server")
// middleware installed…

val response = kernel.handle(
    Request("GET", "/", headers = mapOf(
        "X-Inertia" to "true",
        "X-Inertia-Version" to "client",
    )),
)
// status 409, X-Inertia: true, X-Inertia-Version: server
```

Les clients traitent `409` comme le signal d’un rechargement complet de la page.
