**Search** indexe les enregistrements de l’application et exécute des requêtes de type plein texte contre un moteur remplaçable.

## Enregistrer

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.register(SearchServiceProvider())
```

| Clé | Signification |
|-----|---------|
| `search.default` | Nom du moteur (défaut `collection`) |
| `search.engines.{name}.driver` | `collection`, `array` ou `memory` |

## Types recherchables

```kotlin
data class Post(val id: String, val title: String) : Searchable {
    override fun searchableAs() = "posts"
    override fun getScoutKey() = id
    override fun toSearchableArray() = mapOf("title" to title)
}
```

## Indexer et interroger

```kotlin
Scout.update(post)
val result = Scout.search("posts", "kona")
result.keys() // matching scout keys
Scout.remove(post)
```

</TabItem>
<TabItem label="Java">

```java
Scout.update(article);
SearchResult result = Scout.search("articles", "kona");
```

</TabItem>

## Moteur collection

Le moteur **collection** intégré garde les documents en mémoire et correspond lorsque la requête apparaît dans n’importe quel champ indexé (sans tenir compte de la casse). C’est le pilote concret pour le développement local et les tests ; d’autres moteurs peuvent implémenter `Engine`.
