**Inertia** for Kona lets your JVM app return a **page object** — component name plus props — that a JavaScript client hydrates. The first visit is a normal HTML document; later navigations send the `X-Inertia` header and receive JSON.

Inertia ships as `org.konaframework:kona-inertia` on [Maven Central](https://repo1.maven.org/maven2/org/konaframework/kona-inertia/). Scaffold with `kona new my-app --kit=inertia`, or add the dependency (and provider) with `./grind install inertia` (or `kona grind install inertia`).
