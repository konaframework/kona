Three topics sit beside the panel, and each has its own page. Open the one you need.

- [Tenancy](/docs/firefly/tenancy/) is the tenant menu and `Resource.tenant`.
- [Plugins](/docs/firefly/plugins/) is `FireflyPlugin.register` and `boot`.
- [Import and export](/docs/firefly/import-export/) is the CSV jobs, and `Firefly.test` for a rendered page.

`kona new desk --kit=firefly` is the install path. It is covered on [Installation](/docs/firefly/installation/). It is not a separate runtime.
