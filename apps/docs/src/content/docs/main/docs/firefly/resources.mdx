A resource is one record type on the panel: notes, orders, customers. You bind a model, a form, an infolist, and a table. Drop the class in `resources/` and the panel discovers it. There is no separate registry.

A simple resource is one Manage page. A full resource is list, create, edit, and view. The hello sample uses both. The walkthrough is on [A working app](/docs/firefly/working-app/). This page is the method list.

The types live in `org.konaframework.firefly` (`kona-firefly`).

## A resource the panel can serve

Put the class in the panel's `resources/` folder. A full resource gets list, create, edit, and view pages. Call `page(...)` yourself, or leave the page list empty and `pages()` builds those four.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class OrderResource : Resource("orders") {
    init {
        label("Orders")
        model(Order::class.java)
        form(Schema.make().components(TextInput.make("name")))
        infolist(Infolist.make().components(TextEntry.make("name")))
        table(Table.memory().columns(TextColumn.make("name")))
        relation(RelationManager("lines").related(Line::class.java).titleAttribute("sku"))
    }
}
```

</TabItem>
<TabItem label="Java">

```java
public class OrderResource extends Resource {
    public OrderResource() {
        super("orders");
        label("Orders");
        model(Order.class);
        form(Schema.make().components(TextInput.make("name")));
        infolist(Infolist.make().components(TextEntry.make("name")));
        table(Table.memory().columns(TextColumn.make("name")));
        relation(new RelationManager("lines").related(Line.class).titleAttribute("sku"));
    }
}
```

</TabItem>
</Tabs>

The list page mounts the table and a create action. The create and edit pages mount the form. The view page mounts the infolist. Edit and view also render each relation manager. The panel route is `/{prefix}/{resource}/{page}`, for example `/admin/orders/list`.

`query()` chooses the store from the model type. A Cadence model returns a `ModelBuilder`. A document model fails and names `kona-firefly-document`, which is not part of this release. Any other type fails and tells you to use `Table.memory` for custom rows.

## A simple resource

<FireflyShot file="notes-manage.png" description="The notes Manage page at http://127.0.0.1:4017/admin/notes/manage, with the notes table and the Create, Edit, View, and Delete actions." />

`simple()` keeps one `ManagePage`. Create, edit, view, and delete are header actions, and each one opens the existing dialog. Create and edit put the form schema in that dialog. View puts the infolist in it. Delete asks for confirmation in it. A simple resource rejects `relation(...)`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class NoteResource : Resource("notes") {
    init {
        simple()
        model(Note::class.java)
        form(Schema.make().components(TextInput.make("name")))
        infolist(Infolist.make().components(TextEntry.make("name")))
        table(Table.memory().columns(TextColumn.make("name")))
    }
}
```

</TabItem>
<TabItem label="Java">

```java
public class NoteResource extends Resource {
    public NoteResource() {
        super("notes");
        simple();
        model(Note.class);
        form(Schema.make().components(TextInput.make("name")));
        infolist(Infolist.make().components(TextEntry.make("name")));
        table(Table.memory().columns(TextColumn.make("name")));
    }
}
```

</TabItem>
</Tabs>

The route is `/admin/notes/manage` when the slug is `notes` and the page slug is `manage`.

## Generate one

`./grind make:firefly-resource Order` writes `app/firefly/resources/Order.kt` (or `.java`) with list, create, edit, and view pages plus one relation manager. `./grind make:firefly-resource Note --simple` writes one Manage page and does not write a relation manager. The generated class calls `model(app.models.Order::class.java)`. Create that Cadence model, then let the panel discover the resource directory.

The hello sample mounts a desk panel at `/admin` with a custom page, a widget, a simple note resource, and a full order resource.

## What you build with

| Type | Role |
|------|------|
| `Resource` | Model, form, infolist, table, actions, and pages |
| `RelationManager` | Related records on a full resource's edit and view pages |
| `ManagePage` | The single page of a simple resource |
| `query()` | `ModelBuilder` for a Cadence model |
