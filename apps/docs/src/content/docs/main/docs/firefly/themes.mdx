import { Tabs, TabItem } from '@astrojs/starlight/components';

A theme is a subclass of `FireflyTheme` (`org.konaframework.firefly.support.FireflyTheme`). The panel already draws its layout: the sidebar, the top bar, the page, and the sign-in card. The theme adds CSS classes on that layout, and it can link one stylesheet. The layout stays the panel's own layout.

A hook is a method on `FireflyTheme`, such as `sidebar()` or `brand()`. The method returns class names. Firefly appends those names onto one element the panel already renders. A hook that returns `""` leaves that element on the stock look.

The default theme is `KonaTheme`. The panel uses it until you pass another theme to `theme(...)`.

## Create a theme

From the app directory:

```bash
./grind make:firefly-theme MidnightTheme
```

That writes `src/main/kotlin/app/panels/admin/themes/MidnightTheme.kt`.

`--panel=` chooses the panel package. `--panel=staff` writes `src/main/kotlin/app/panels/staff/themes/MidnightTheme.kt`.

`--lang=kotlin` or `--lang=java` chooses the language. `--lang=java` writes `src/main/java/app/panels/admin/themes/MidnightTheme.java`. When you omit `--lang`, Grind uses Java if the app already has a `.java` file under `src/main/java`, and Kotlin otherwise.

The class extends `FireflyTheme`. `id()` returns `midnighttheme`. `stylesheet()` returns `null`. Every hook returns `""`.

## Register the theme

Call `theme(...)` on the panel and pass an instance. Return that same panel from `panel(...)`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
package app.panels.admin

import app.panels.admin.themes.MidnightTheme
import org.konaframework.firefly.Panel as FireflyPanel

class Panel : FireflyPanel() {
    override fun panel(panel: FireflyPanel): FireflyPanel =
        panel
            .id("admin")
            .theme(MidnightTheme())
}
```

</TabItem>
<TabItem label="Java">

```java
package app.panels.admin;

import app.panels.admin.themes.MidnightTheme;

public class Panel extends org.konaframework.firefly.Panel {
    @Override
    public org.konaframework.firefly.Panel panel(org.konaframework.firefly.Panel panel) {
        return panel
            .id("admin")
            .theme(new MidnightTheme());
    }
}
```

</TabItem>
</Tabs>

The command prints the same call: `panel.theme(MidnightTheme())` in Kotlin, and `panel.theme(new MidnightTheme())` in Java.

## Style the chrome with classes

Each hook returns class names separated by spaces. Firefly appends them to the element in the table. `""` leaves the stock look.

A darker sidebar, a tighter brand, and a wider page are three places to start. The [stylesheet below](#add-a-stylesheet) defines those three classes, plus the nav hover and the sign-in card.

| Hook | Element | Example |
| --- | --- | --- |
| `panel()` | `.ff-panel` | `midnight` |
| `sidebar()` | `aside.ff-sidebar` | `midnight-sidebar` — darker sidebar |
| `topbar()` | `header.ff-topbar` | `midnight-topbar` |
| `brand()` | `.ff-sidebar-brand`, `.ff-topbar-brand`, `.ff-auth-brand` | `midnight-brand` — tighter brand |
| `navigation()` | `nav.ff-nav` | `midnight-nav` |
| `navigationItem()` | `.ff-nav-item` | `midnight-item` |
| `navigationGroup()` | `.ff-nav-group` | `midnight-group` |
| `content()` | `main.ff-body` | `midnight-wide` — wider page |
| `pageHeader()` | `.ff-page-header` | `midnight-header` |
| `footer()` | `footer.ff-footer` | `midnight-footer` |
| `sidebarFoot()` | `.ff-sidebar-foot` | `midnight-foot` |
| `userMenu()` | `.ff-user-menu` | `midnight-user` |
| `column()` | `.ff-column` | `midnight-column` |
| `scroll()` | `.ff-scroll` | `midnight-scroll` |
| `auth()` | `body.ff-auth` | `midnight-auth` |
| `authCard()` | `.ff-auth-panel` | `midnight-card` |

`brand()` is one hook for the three brand elements, so the sidebar, the top bar, and the sign-in brand get the same classes.

`column()` matches every `.ff-column`, including table cells. Use `content()` for the page.

## Add a stylesheet

`stylesheet()` returns the URL of a CSS file. Firefly writes `<link rel="stylesheet" href="...">` at the end of `<head>`, after the stock `<style>` block. `null` or a blank string adds no link.

Put the file in the app's `public/` directory. That directory is the web root, so `public/css/midnight.css` is served at `/css/midnight.css`:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
override fun stylesheet(): String? = "/css/midnight.css"
```

</TabItem>
<TabItem label="Java">

```java
@Override public String stylesheet() { return "/css/midnight.css"; }
```

</TabItem>
</Tabs>

A full `https://` URL works the same way when the file is hosted elsewhere.

Write normal CSS. Name the `ff-*` element and the class the hook added. Stock rules use selectors such as `.ff-panel .ff-sidebar`, and the sign-in card is `.ff-auth-panel`. Write your rule at that depth so it applies. The link comes after the stock `<style>` block.

The sign-in page is `body.ff-auth`. Rules for the card and the sign-in brand use `.ff-auth`.

`extraCss()` still appends a string of CSS, wrapped in `.ff-panel { ... }`. Put sign-in rules in the linked file, where `.ff-auth` is in reach.

This theme fills the hooks from the table. The other hooks stay `""`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class MidnightTheme : FireflyTheme() {
    override fun id(): String = "midnighttheme"

    override fun stylesheet(): String? = "/css/midnight.css"

    override fun sidebar(): String = "midnight-sidebar"

    override fun brand(): String = "midnight-brand"

    override fun navigationItem(): String = "midnight-item"

    override fun content(): String = "midnight-wide"

    override fun authCard(): String = "midnight-card"
}
```

</TabItem>
<TabItem label="Java">

```java
public class MidnightTheme extends FireflyTheme {
    @Override public String id() { return "midnighttheme"; }

    @Override public String stylesheet() { return "/css/midnight.css"; }

    @Override public String sidebar() { return "midnight-sidebar"; }

    @Override public String brand() { return "midnight-brand"; }

    @Override public String navigationItem() { return "midnight-item"; }

    @Override public String content() { return "midnight-wide"; }

    @Override public String authCard() { return "midnight-card"; }
}
```

</TabItem>
</Tabs>

`public/css/midnight.css`:

```css
/* Darker sidebar. Stock link color is set on the anchor. */
.ff-panel .ff-sidebar.midnight-sidebar {
  background: #1c1917;
  color: #e7e5e4;
}

.ff-panel .ff-sidebar.midnight-sidebar .ff-nav-item > a {
  color: #e7e5e4;
}

/* Tighter brand. The logo is .ff-brand-logo, the fallback mark is the
   sidebar ::before, and the name is .ff-brand. On the top bar the brand
   class sits on the mark itself. */
.ff-panel .midnight-brand .ff-brand-mark,
.ff-panel .ff-brand-mark.midnight-brand,
.ff-auth .midnight-brand .ff-brand-mark {
  gap: 0.35rem;
}

.ff-panel .ff-sidebar-brand.midnight-brand:not(.ff-sidebar-brand--logo)::before {
  width: 1.35rem;
  height: 1.35rem;
}

.ff-panel .midnight-brand .ff-brand-logo,
.ff-auth .midnight-brand .ff-brand-logo {
  height: 1.35rem;
}

.ff-panel .midnight-brand .ff-brand,
.ff-auth .midnight-brand .ff-brand {
  font-size: 1rem;
  line-height: 1.2;
}

/* Nav item hover. Cluster labels keep the stock hover. */
@media (hover: hover) {
  .ff-panel .ff-nav-item.midnight-item:not(.ff-cluster) > a:hover {
    background: #44403c;
    color: #fafaf9;
  }
}

/* Wider page. The page block inside main.ff-body is .ff-page. */
.ff-panel .ff-body.midnight-wide .ff-page {
  max-width: 90rem;
}

/* Sign-in card. */
body.ff-auth .ff-auth-panel.midnight-card {
  background: #fffbeb;
  border-color: #d6d3d1;
  box-shadow: none;
}
```

The brand rule is on `.ff-sidebar-brand`, `.ff-topbar-brand`, and `.ff-auth-brand`, because `brand()` adds `midnight-brand` to all three. The mark and the name change together, and the gap between them is `0.35rem`.

## Check the panel and the sign-in page

Restart the app. Open the panel, for example `/admin`, and the sign-in page, `/admin/login`.

The same theme is on both. The sidebar, the nav, and the page are on the panel. The brand and the auth card are on the sign-in page. A class from `sidebar()` shows on the panel. A class from `authCard()` shows on the sign-in page. A class from `brand()` shows on both.

## Start from the stock theme

`KonaTheme` is the stock theme. The panel uses it when you never call `theme(...)`.

Your class extends `FireflyTheme`. Every hook there returns `""`. Override only the hooks you care about. Leave the others returning `""`, or delete those empty overrides. The generated file lists every hook so the names are in front of you.

The stock palette stays until you change it. The built-in CSS reads these custom properties on `.ff-panel` and `.ff-auth`: `--ff-primary`, `--ff-accent`, `--ff-surface`, `--ff-heading`, `--ff-font`, `--ff-radius`, `--ff-sidebar-width`, `--ff-topbar-height`, and `--ff-body`. Set them in `midnight.css` when you want different colors, type, or widths:

```css
.ff-panel,
.ff-auth {
  --ff-primary: #c2410c;
  --ff-sidebar-width: 18rem;
}
```
