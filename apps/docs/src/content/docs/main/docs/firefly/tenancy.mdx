Add a tenant when one panel serves more than one customer and a resource should only query that customer’s rows. The link is a label in the top bar. The id is what the current request filters on.

You add the tenant. Your resource names the column. The link sets `?tenant=acme`. While that request renders, `FireflyTenant.id()` is `acme`.

<FireflyShot file="tenant-menu.png" description="A panel top bar with a tenant link labeled Acme that sets the tenant query parameter to acme." />

## Filter a resource by the selected tenant

`tenant(Tenant("acme").label("Acme"))` adds the link. A resource that calls `tenant("tenant_id")` adds that column to `query()` when the id is set. A Cadence model still returns a `ModelBuilder`. An unknown tenant id fails at the page and names the id.

A blank tenant id or a blank label throws `FireflyException`. A blank column name throws `Tenant column is blank`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
Panel().path("admin").tenant(Tenant("acme").label("Acme"))
Resource("orders").model(Order::class.java).tenant("tenant_id")
```

</TabItem>
<TabItem label="Java">

```java
new Panel().path("admin").tenant(new Tenant("acme").label("Acme"));
new Resource("orders").model(Order.class).tenant("tenant_id");
```

</TabItem>
</Tabs>

Open `/admin/orders/list?tenant=acme`. The orders query includes `tenant_id`. `label` accepts a string or a closure that receives `Get`. `FireflyTenant.use(id) { ... }` sets the id for the current thread and restores the previous value when the block returns. `mount` already does that around the page response. Call `use` yourself in a test.

`FireflyTenant.id()` is null when the query string has no `tenant` parameter.

## Methods

| Type | Methods |
|------|---------|
| `Tenant` | `label(value)`, `label(provider)`, `label()` |
| `Panel` | `tenant(tenant)` |
| `Resource` | `tenant(column)` |
| `FireflyTenant` | `id()`, `use(id, supplier)` |
