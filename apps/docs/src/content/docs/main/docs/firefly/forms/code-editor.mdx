`CodeEditor` is a plaintext editor with a highlighted layer under the textarea (CodeMirror / Shiki attributes on the host). It is not a rich-text or markdown surface. Default language is `plaintext`.

## Add the field

<Tabs syncKey="lang">

    .label("Snippet")
    .language("kotlin")
    .wrap(true)
```

</TabItem>

## Options

| Method | Effect |
|--------|--------|
| `language(value)` | Grammar id (non-blank; throws if empty) |
| `language()` | Current language string |
| `wrap()` / `wrap(on)` | Soft wrap (`wrap="soft"` vs `wrap="off"`) |
| `CodeEditor.languages()` | Ids shipped with the module (`FormAssets.languages()`) |

The head shows the current language label. The highlight `<pre>` mirrors the textarea content for display; the textarea is what posts.

<Tabs syncKey="lang">

CodeEditor.make("json")
    .label("Payload")
    .language("json")
    .wrap(false)
    .placeholder("{ }")
    .helperText("Must be valid JSON on the server")

val langs = CodeEditor.languages()

```

## Languages

`CodeEditor.languages()` reads the module’s `shiki-languages.txt` resource (for example `kotlin`, `java`, `json`, `typescript`, `yaml`). Pass any of those ids to `language(...)`. Blank language strings throw. The host attributes include `data-ff-editor="codemirror"` and `data-ff-highlighter="shiki"`.

For markdown with preview, use [`MarkdownEditor`](/docs/firefly/forms/markdown-editor/). For formatted prose, use [`RichEditor`](/docs/firefly/forms/rich-editor/).

## Configure defaults

`CodeEditor.configureUsing { field -> ... }` runs for every new `make(...)` until you clear it with `configureUsing(null)`.
