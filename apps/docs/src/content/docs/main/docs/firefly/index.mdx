**Kona Firefly** (short name **Firefly**) is Kona’s application-panel product. A panel is a themed shell — sidebar, top bar, body, and footer — plus dialogs that actions can open. Firefly renders that chrome on the server and keeps interactive pieces on [Wire](/docs/wire/) and Alpine.

(Brief nod: Firefly occupies the same problem space as full application-panel kits. The rest of these pages describe Firefly on its own terms.)

Nine artifacts are in the repository today.

`org.konaframework:kona-firefly-support`, package `org.konaframework.firefly.support`, gives you themes, scoped CSS, panel chrome, render hooks, icons, and the shared dialog. It does not register HTTP routes, middleware, or views. Adding it to an existing application does not change routes you already defined.

`org.konaframework:kona-firefly-schemas`, package `org.konaframework.firefly.schemas`, builds the schema tree: layouts, text, icons, images, state, and live updates. Read [Schemas](/docs/firefly/schemas/) for that API.

`org.konaframework:kona-firefly-actions`, package `org.konaframework.firefly.actions`, builds buttons, links, groups, and confirmation dialogs. Read [Actions](/docs/firefly/actions/) for that API.

`org.konaframework:kona-firefly-infolists`, package `org.konaframework.firefly.infolists`, renders read-only entries on that tree. Read [Infolists](/docs/firefly/infolists/).

`org.konaframework:kona-firefly-tables`, package `org.konaframework.firefly.tables`, lists records with columns, filters, search, sort, and pages. Read [Tables](/docs/firefly/tables/) for that API.

`org.konaframework:kona-firefly-forms`, package `org.konaframework.firefly.forms`, adds form fields on that schema: text, choices, dates, editors, uploads, repeaters, and builders. Read [Forms](/docs/firefly/forms/) for that API.

`org.konaframework:kona-firefly-notifications`, package `org.konaframework.firefly.notifications`, flashes a toast, lists database notices in a bell, and marks a page for broadcast refresh. Read [Notifications](/docs/firefly/notifications/).

`org.konaframework:kona-firefly-widgets`, package `org.konaframework.firefly.widgets`, renders stats, charts, tables, and account cards on their own and on a page or dashboard. Read [Widgets](/docs/firefly/widgets/).

`org.konaframework:kona-firefly`, package `org.konaframework.firefly`, mounts a panel at `/admin` or at the site root, with navigation, auth screens, and pages discovered from the panel directory. Read [Panel](/docs/firefly/panel/).

## Add the module

Depend on the Firefly modules through the Kona BOM (`org.konaframework`). The first Firefly release train is **0.4.x**. Until that train is published, use the modules from a Kona checkout:

```kotlin
dependencies {
    implementation(project(":kona-firefly-support"))
    implementation(project(":kona-firefly-schemas"))
    implementation(project(":kona-firefly-actions"))
    implementation(project(":kona-firefly-infolists"))
    implementation(project(":kona-firefly-tables"))
    implementation(project(":kona-firefly-forms"))
    implementation(project(":kona-firefly-notifications"))
    implementation(project(":kona-firefly-widgets"))
    implementation(project(":kona-firefly"))
}
```

Java projects use the same coordinates. Every public type in this package is callable from Java.

## What you build with

| Type | Role |
|------|------|
| [`FireflyTheme`](/docs/firefly/themes/) | Colors, font, radius, and optional replacement HTML for a chrome slot |
| [`KonaTheme`](/docs/firefly/themes/) | Built-in caramel theme (`id` is `kona`) |
| [`Stylesheet`](/docs/firefly/themes/) | Turns a theme into CSS variables scoped under `.ff-panel` |
| [`Panel`](/docs/firefly/chrome/) | Picks the theme, layout, hooks, and partial overrides, then renders |
| [`Dialog`](/docs/firefly/dialog/) | One dialog component: modal, sidebar, or fullscreen |
| [`Action`](/docs/firefly/actions/) | Button, link, confirmation, and dialog body |
| `Icon` | Inline SVG icons: `HOME`, `BARS`, `USER`, `X` |
| `FireflyException` | Unchecked failure for a bad width, a missing hook marker, or CSS that escapes the panel |

## A shell in one call

Kotlin:

```kotlin
val html = Panel()
    .theme(KonaTheme())
    .hook(Hook.BODY_START, "<p>Welcome</p>")
    .render()
```

Java:

```java
String html = new Panel()
    .theme(new KonaTheme())
    .hook(Hook.BODY_START, "<p>Welcome</p>")
    .render();
```

`render()` returns one root `<div class="ff-panel">` with a `<style>` block, then the sidebar, top bar, body, and footer. The body partial contains the hook text `Welcome`.

## Icons

`Icon.HOME`, `Icon.BARS`, `Icon.USER`, and `Icon.X` each expose `path` and `svg()`. `svg()` returns an `<svg class="ff-icon">` whose path data is HTML-escaped.

`Icon.fromName` accepts those names in any letter case (`"HoMe"` is `HOME`). Any other name throws `FireflyException` with the message `Unknown icon [<name>]`.

```kotlin
Icon.fromName("bars").svg()
```

```java
Icon.fromName("bars").svg();
```

## Failure type

`FireflyException` extends `RuntimeException`. Callers do not have to declare it. The message names the bad value: the dialog width, the theme id, the partial slot, or the icon name.
