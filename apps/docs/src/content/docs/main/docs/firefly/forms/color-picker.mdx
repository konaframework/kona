`ColorPicker` stores a color string. The UI is a native color swatch next to a text input. Format helpers set both the placeholder and the validation regex. Default format is hex.

## Formats

| Method | Stored shape | Validation regex (conceptually) |
|--------|--------------|----------------------------------|
| `hex()` | `#RRGGBB` (default) | `^#[0-9A-Fa-f]{6}$` |
| `rgb()` | `rgb(r, g, b)` | `^rgb\(\d{1,3}, ?\d{1,3}, ?\d{1,3}\)$` |
| `hsl()` | `hsl(h, s%, l%)` | `^hsl\(\d{1,3}, ?\d{1,3}%, ?\d{1,3}%\)$` |
| `format()` | Current format name (`"hex"`, `"rgb"`, or `"hsl"`) | — |
| `normalize(raw)` | Returns the trimmed string if it matches the format, else `null` | — |

The swatch uses `type="color"`. When the text value is not a valid hex, the swatch falls back to `#000000`. Placeholders default to `#000000`, `rgb(0, 0, 0)`, or `hsl(0, 0%, 0%)` unless you set `placeholder(...)`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
ColorPicker.make("ink").rgb()
ColorPicker.make("wash").hsl()

val cleaned = ColorPicker.make("tmp").hex().normalize("#aabbcc")
// cleaned == "#aabbcc"
```

</TabItem>
<TabItem label="Java">

```java
ColorPicker.make("ink").rgb();
ColorPicker.make("wash").hsl();

String cleaned = ColorPicker.make("tmp").hex().normalize("#aabbcc");
// cleaned.equals("#aabbcc")
```

</TabItem>
</Tabs>

## Validation

Each format appends a `regex:` rule in `validationRules`. Combine with `required()` when empty values are not allowed. Blank or whitespace input returns `null` from `normalize`. Invalid strings for the active format also return `null` — they do not coerce into another format.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
ColorPicker.make("brand")
    .hex()
    .required()
    .helperText("Six-digit hex, including #")
    .liveOnBlur()
```

</TabItem>
<TabItem label="Java">

```java
ColorPicker.make("brand")

    .required()
    .helperText("Six-digit hex, including #")
    .liveOnBlur();
```

</TabItem>

## Configure defaults

`ColorPicker.configureUsing { field -> ... }` runs for every new `make(...)` until you clear it with `configureUsing(null)`.
