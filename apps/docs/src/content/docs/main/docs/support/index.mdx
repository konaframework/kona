The `kona-support` module ships everyday helpers used across apps and the framework. For number and money formatting, see [Numbers](./numbers/). For SVG icons (Heroicons by default, drop-in sets), see [Icons](./icons/) (`kona-icons`).

## Collections

`Collection` wraps a list with a fluent Laravel-shaped API. Create one with `collect(...)`, `Collection.make(...)`, or `Collection.of(...)`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val names = collect(users)
    .where("active", true)
    .pluck("name")
    .filter { it != null }
    .join(", ")

collect(1, 2, 3, 4)
    .reject { it % 2 == 0 }
    .partition { it > 1 }

Collection.times(3) { "row-$it" }
Collection.wrap(listOf(1, 2)).merge(listOf(3))
```

Useful methods include `map`, `flatMap`, `filter`, `reject`, `where` / `firstWhere`, `reduce`, `chunk`, `collapse`, `flatten`, `sum` / `avg` / `min` / `max`, `keyBy`, keyed `pluck`, `groupBy`, `partition`, `sortBy`, `unique`, `sole`, `diff` / `intersect`, `mapWithKeys`, `countBy`, `slice` / `nth` / `pad`, `pop` / `shift` / `prepend`, and `when` / `unless` / `whenEmpty`.

</TabItem>
<TabItem label="Java">

```java
Collection<Integer> nums = Collection.make(1, 2, 3, 4);
nums.reject(n -> n % 2 == 0).toList();
Collection.times(2, i -> i);
Collection.wrap(List.of(1, 2)).join("-");
```

</TabItem>
</Tabs>

## Lazy collections

`lazy()` on a `Collection` returns a `LazyCollection`. `map`, `filter`, `reject`, `take`, `skip`, `unique`, `flatMap`, and `tap` wait until you iterate, call `first`, `count`, or `isEmpty`, or `collect()` back into a `Collection`. `LazyCollection.make`, `of`, and `empty` build one directly.

```kotlin
val firstEven = Collection.make(1, 2, 3, 4)
    .lazy()
    .filter { it % 2 == 0 }
    .take(1)
    .first()
```

## Higher-order proxies

`higher(operation)` applies that operation to a property or a no-arg method on every item. `get` reads a map key, then a `get` or `is` accessor, then a field. `call` invokes a public no-arg method. Operations are `map`, `filter`, `reject`, `each`, `sum`, `every`, and `first`. A value counts as present when it is `true`, a non-zero number, a non-empty string, or a non-empty iterable. `map`, `filter`, and `reject` stay lazy when the proxy comes from a `LazyCollection`.

```kotlin
collect(users).higher("map").get("name")
collect(users).higher("filter").get("active")
collect(users).higher("each").call("ping")
collect(users).higher("sum").get("votes")
```

```java
rows.higher("map").get("name");
rows.higher("each").call("ping");
```

## Strings

```kotlin
Str.slug("Hello World")          // hello-world
Str.of("hello_world").camel()    // helloWorld
Str.headline("hello_world")      // Hello World
Str.mask("5551234", "*", 0, 3)   // ***1234
Str.beforeLast("a/b/c", "/")     // a/b
Str.padLeft("7", 3, "0")         // 007
Str.plural("currency")           // currencies
Str.singular("companies")        // company
```

`Stringable` from `Str.of(...)` chains the same transforms (`lower`, `snake`, `slug`, `limit`, `append`, `finish`, …). `Str.plural` / `Str.singular` use English inflection rules (including irregulars like currency → currencies); Cadence `foreignId(...).constrained()` uses the same pluralizer to guess the related table.

## Numbers

`Number` formats numbers, money, percentages, file sizes, and short forms, and parses locale-formatted input back into exact `BigDecimal` values. See [Numbers](./numbers/) for the full guide.

```kotlin
Number.format(1234.5)                          // 1,234.5
Number.currency(BigDecimal("1250"), "KES", "en_KE") // Ksh1,250.00
Number.abbreviate(1_250_000, 2)                // 1.25M
```

## Dates

`KonaDate` is the fluent date/time type in `kona-support` — a convenient wrapper over a UTC `Instant` plus a zone used for calendar math and formatting. JSON (`Response.json`, Cadence `toJson`, `org.konaframework.support.json.Json.stringify`) encodes a `KonaDate` as an ISO-8601 string — the same shape used for `Instant` and the other `java.time` types.

### Create and parse

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
KonaDate.now()
KonaDate.today()
KonaDate.yesterday()
KonaDate.tomorrow()
KonaDate.create(2024, 1, 15, 12, 30, 0)
KonaDate.createFromDate(2024, 1, 15)
KonaDate.createFromTimestamp(1_704_000_000)
KonaDate.ofInstant(user["created_at"] as Instant)
KonaDate.parse("2024-01-15T12:30:00Z")
KonaDate.parse("2024-01-15 12:30:00")
KonaDate.parse("2024-01-15")
KonaDate.ofLocalDate(LocalDate.of(2024, 1, 15))
```

</TabItem>
<TabItem label="Java">

```java
KonaDate.now();
KonaDate.today();
KonaDate.yesterday();
KonaDate.tomorrow();
KonaDate.create(2024, 1, 15, 12, 30, 0);
KonaDate.createFromDate(2024, 1, 15);
KonaDate.createFromTimestamp(1_704_000_000L);
KonaDate.ofInstant((Instant) user.get("created_at"));
KonaDate.parse("2024-01-15T12:30:00Z");
KonaDate.ofLocalDate(LocalDate.of(2024, 1, 15), ZoneOffset.UTC);
```

</TabItem>
</Tabs>

Parse accepts ISO instants (`…Z`), offset and zoned strings, `yyyy-MM-dd HH:mm:ss` / `T` local datetimes (read as UTC), and calendar dates. Set the process default with `KonaDate.setDefaultTimezone(zone)` (apps usually wire this from `app.timezone`).

### Mutate, boundaries, and zones

```kotlin
val d = KonaDate.parse("2024-01-15T12:30:00Z")
d.addMonths(1).startOfMonth().toDateString()
d.endOfWeek().toDateTimeString()
d.startOfQuarter().quarter()
d.setHour(9).setMinute(0)
d.setTimezone(ZoneId.of("Africa/Nairobi")).toDateTimeString() // same instant, new zone
d.shiftTimezone(ZoneId.of("Africa/Nairobi"))                  // keep wall clock
d.utc().toIso()
```

Arithmetic: `add` / `sub` (and singular `addDay` / `subMonth`, …) for milliseconds through years. Boundaries: `startOf` / `endOf` for second, minute, hour, day, ISO week (Monday–Sunday), month, quarter, and year. Getters: `year`, `month`, `day`, `hour`, `minute`, `second`, `dayOfWeek`, `weekOfYear`, `quarter`, …

### Compare and humanize

```kotlin
d.isBefore(other)
d.eq(other) / d.gt(other) / d.lte(other)
d.between(start, end)                 // inclusive by default
d.betweenExcluded(start, end)
d.isWeekend() / d.isMonday()
d.isToday() / d.isYesterday() / d.isCurrentMonth()
d.min(other) / d.max(other)
d.closest(a, b) / d.farthest(a, b)
d.diffInDays(other)
d.diffInHours(other, absolute = true)
d.age()                               // whole years until now
d.diffForHumans()                     // "3 hours ago" / "1 day from now"
d.diffForHumans(other)                // "2 weeks before" / "after"
d.ago() / d.fromNow()
```

`diffForHumans`, `ago`, and `fromNow` use the largest calendar unit first (years → months → weeks → days → hours → minutes → seconds). Pass a `Locale`, or call `KonaDate.setHumanLocale`, to select a phrase pack. Packs: English, Spanish, French, German, Italian, Portuguese (`pt` and `pt-BR`), Dutch, Swedish, Danish, Norwegian Bokmål (`nb`, `no`), Norwegian Nynorsk (`nn`), Simplified Chinese (`zh`, `zh-CN`, `zh-Hans`), Traditional Chinese (`zh-TW`, `zh-Hant`), Japanese, Korean, Indonesian, Turkish, and Russian. Any other locale uses English. `KonaDate.resetHumanLocale()` restores English. Format helpers: `format(pattern)`, `toDateString`, `toFormattedDateString`, `toDateTimeString`, `toTimeString`, `toIso` / `toIso8601String`, `toRfc3339String`.

HTTP JSON example:

```json
{"created_at":"2024-01-15T12:30:00Z"}
```

## Arrays / maps

`Arr.get`, `Arr.set`, `Arr.has`, `Arr.forget`, `Arr.only`, `Arr.except`, `Arr.wrap`, `Arr.flatten`, `Arr.pluck`, and `Arr.dot` work with nested dotted keys (`user.name`).

```kotlin
val row = linkedMapOf<String, Any?>()
Arr.set(row, "user.name", "Ada")
Arr.forget(row, "user.name")
Arr.dot(mapOf("user" to mapOf("age" to 1))) // user.age → 1
```

## Localization

```kotlin
val t = Translator().addLines("en", mapOf("hi" to "Hello :name"))
t.get("hi", mapOf("name" to "Ada"))
Lang.setTranslator(t)
translate("hi", mapOf("name" to "Ada"))
```

```java
Translations.__("hi", Map.of("name", "Ada"));
```

Register `SupportServiceProvider` to bind a shared `Translator`. If `lang.path` is set or `{base}/lang` exists, JSON and `key=value` files are loaded automatically (`lang/en.json`, `lang/en/messages.json`, `lang/en.properties`, and so on).
