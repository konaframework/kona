**Broadcasting** pushes application events to named channels. Kona ships a first-party **Reverb-class** Netty websocket server (Pusher protocol), `/broadcasting/auth` channel authorization, optional Redis scale-out, and a JavaScript Echo client with Vue composables.

## Register

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.register(BroadcastServiceProvider())
```

Config keys (`config/Broadcasting`):

| Key | Meaning |
|-----|---------|
| `broadcasting.default` | Connection name (default `log`) |
| `broadcasting.connections.{name}.driver` | `log`, `null` / `none`, `websocket` / `ws`, `reverb`, `pusher`, `ably` |
| `broadcasting.connections.websocket.key/secret/host/port` | Reverb app credentials and bind address |
| `broadcasting.reverb.scaling` | `false` or `redis` for horizontal fan-out |

## ShouldBroadcast events

```kotlin
class OrderShipped : ShouldBroadcast {
    override fun broadcastOn() = listOf(Channel.publicChannel("orders"))
    override fun broadcastAs() = "order.shipped"
    override fun broadcastWith() = mapOf("id" to 42)
}

Broadcast.event(OrderShipped())
```

## Reverb websocket server

Start the Pusher-protocol server (separate process or `--once` in tests):

```bash
./grind reverb:start
# ws://127.0.0.1:8080/app/{REVERB_APP_KEY}
```

Point the default connection at `reverb` (or `websocket` for in-process listeners) and broadcast as usual. Private / presence channel names are normalized to Pusher wire form (`private-…`, `presence-…`) by [Channel.pusherName].

Embed the hub in-process:

```kotlin
val hub = Broadcast.manager().hub()
val reverb = Broadcast.manager().reverb()
ReverbServer(hub, key = "app-key", host = "127.0.0.1", port = 8080).start()
```

### Redis scale-out

Set `broadcasting.reverb.scaling=redis` (and register `RedisServiceProvider`). Each Reverb node publishes to Redis pub/sub (`kona:reverb` by default) so sibling nodes fan events to their local sockets.

## Channel authorization

Register `routes/channels` callbacks and POST to `/broadcasting/auth` (registered by `BroadcastServiceProvider` when HTTP is present):

```kotlin
Broadcast.channel("orders.{orderId}") { user, params ->
    user != null && params[0] == "42"
}

Broadcast.channel("chat.{room}") { user, _ ->
    mapOf("user_id" to "1", "user_info" to mapOf("name" to "Ada"))
}
```

Private channels return `{ "auth": "key:signature" }`. Presence channels also include `channel_data`.

## toOthers / socket exclusion

```kotlin
Broadcast.socket(request.header("X-Socket-Id"))
Broadcast.to(Channel.publicChannel("orders")).toOthers().event("typing", mapOf("user" to 1))
```

`ShouldBroadcast` events also honor the thread-local socket id set via `Broadcast.socket(...)`.

## Ad-hoc broadcasts

```kotlin
Broadcast.to(Channel.publicChannel("orders"), Channel.privateOf("user.1"))
    .event("order.shipped", mapOf("id" to 42))
```

## Drivers

| Driver | Behavior |
|--------|----------|
| `log` | Stores payloads in memory — ideal for tests |
| `null` / `none` | No-op |
| `websocket` / `ws` | In-process fan-out (`WebsocketBroadcaster`) |
| `reverb` | Local Reverb hub (+ optional Redis scale-out) |
| `pusher` | Optional HTTP trigger to Pusher / compatible hosts |
| `ably` | Optional Ably REST publish |

## JavaScript client (`@konaframework/echo`)

```bash
npm install @konaframework/echo
```

```js
import Echo from '@konaframework/echo'

window.Echo = new Echo({
  key: import.meta.env.VITE_REVERB_APP_KEY,
  wsHost: import.meta.env.VITE_REVERB_HOST ?? '127.0.0.1',
  wsPort: import.meta.env.VITE_REVERB_PORT ?? 8080,
  forceTLS: false,
  authEndpoint: '/broadcasting/auth',
})

Echo.channel('orders').listen('order.shipped', (e) => console.log(e))
Echo.private(`user.${id}`).listen('.OrderUpdated', handler)
Echo.join('kitchen').here(console.log).joining(console.log).leaving(console.log)
```

### Vue composables

```js
import { useEcho, useEchoPublic } from '@konaframework/echo/vue'

useEchoPublic('orders', {
  'order.shipped': (payload) => { /* … */ },
})

useEcho(`orders.${orderId}`, {
  OrderUpdated: (payload) => { /* … */ },
})
```

Wire’s `effects.echo` listeners continue to work when `window.Echo` is present.
