---
title: Página de bienvenida
description: Ruta mínima que renderiza Pages/Welcome con una prop de mensaje.
---

```kotlin
router.get("/") {
    Inertia.render(
        "Pages/Welcome",
        mapOf("message" to "Welcome to Kona Inertia"),
    )
}
```

```java
router.get("/", request ->
    Inertia.render("Pages/Welcome", Map.of("message", "Welcome to Kona Inertia"))
);
```

Primera visita → HTML `data-page` con el nombre del componente. Visita Inertia → JSON con las mismas props.
