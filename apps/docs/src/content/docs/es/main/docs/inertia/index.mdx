**Inertia** para Kona permite que tu aplicación JVM devuelva un **objeto de página** — nombre del componente más props — que un cliente JavaScript hidrata. La primera visita es un documento HTML normal; las navegaciones posteriores envían la cabecera `X-Inertia` y reciben JSON.

Inertia se publica como `org.konaframework:kona-inertia` en [Maven Central](https://repo1.maven.org/maven2/org/konaframework/kona-inertia/). Crea el esqueleto con `kona new my-app --kit=inertia`, o añade la dependencia (y el provider) con `./grind install inertia` (o `kona grind install inertia`).
