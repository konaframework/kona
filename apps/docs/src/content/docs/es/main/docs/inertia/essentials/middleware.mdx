`HandleInertiaRequests` (typealias `InertiaMiddleware`) should sit on the HTTP kernel for all Inertia routes.

## Lifecycle

1. Resolve `Inertia.manager()` (requires booted `InertiaServiceProvider`)
2. `setRequest(request)`
3. Merge `defaultShare(request)` + `share(request)` → `shareForRequest`
4. Optional `version(request)` → updates `manager.version`
5. If `versionConflict(request)` → return decorated `409` + `X-Inertia-Location`
6. Else run the next handler
7. Empty Inertia `200` with no body → `Response.back(request)`
8. Inertia `302` after `PUT` / `PATCH` / `DELETE` → status `303`
9. `decorate(response)`
10. `finally` → `setRequest(null)`

## Overrides

| Method | Default | Purpose |
|--------|---------|---------|
| `defaultShare(request)` | `errors` + `flash` | Built-in shared props |
| `share(request)` | empty map | App props (merged after defaults) |
| `version(request)` | `null` (keep manager version) | Dynamic asset version |
| `resolveValidationErrors` / `resolveFlash` | session-backed | Customize error/flash shapes |

## Registration

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.resolve(HttpKernel::class.java).pushMiddleware(HandleInertia())
```

</TabItem>
<TabItem label="Java">

```java
app.resolve(HttpKernel.class).pushMiddleware(new HandleInertia());
```

</TabItem>
</Tabs>

Push **after** `InertiaServiceProvider` has booted so the facade manager is set.
