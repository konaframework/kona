---
title: Correo
description: Envía mailables por transportes log o SMTP.
---

Construye mensajes con `Mailable` / `MailMessage` y envíalos a través de un `Mailer`.

## Inicio rápido

```kotlin
class WelcomeMail : Mailable() {
    override fun envelope() = Envelope(subject = "Welcome", from = Address("app@example.com"))
    override fun content() = Content(html = "<p>Hi</p>", text = "Hi")
}

app.resolve(Mailer::class.java).to("user@example.com").send(WelcomeMail())
```

Registra `MailServiceProvider`. Drivers:

| Transporte | Configuración |
| --- | --- |
| `log` / `array` | Registra los mensajes (útil en pruebas) |
| `smtp` | `host`, `port`, `username`, `password` |

Valores por defecto: `mail.default`, `mail.from.address`, `mail.from.name`.
