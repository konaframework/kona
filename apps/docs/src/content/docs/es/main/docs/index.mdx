Este es el centro de documentación de **Kona**. La página de marketing vive en la raíz del sitio; todo lo de abajo es cómo construir con el framework.

Kona arranca una **aplicación**, enchufa funciones con **service providers**, busca servicios en un **contenedor** y responde HTTP con **rutas** y **middleware**. Las mismas API funcionan desde Kotlin y Java. El CLI **grind** genera el esqueleto y sirve tu proyecto.

Usa la barra lateral en orden si eres nuevo: **Primeros pasos** → **Lo esencial** → **Crema**, luego **Profundizar**, y entra en **Seguridad**, **Base de datos**, **Frontend**, **Wire**, **Inertia**, **Firefly**, **Pruebas** y **Paquetes y herramientas** cuando los necesites.
