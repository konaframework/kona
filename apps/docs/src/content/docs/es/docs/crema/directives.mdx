Consulta rápida de la sintaxis de Crema. Para explicaciones y ejemplos completos, sigue los enlaces de «Guía».

## Ecos y comentarios

| Sintaxis | Propósito | Guía |
|--------|---------|-------|
| `{{ expr }}` | Salida escapada | [Renderizado](/docs/crema/rendering/) |
| `{!! expr !!}` | Salida HTML cruda | [Renderizado](/docs/crema/rendering/) |
| `{{ url(path) }}` / `{{ route(name) }}` / `{{ asset(path) }}` | URL de la app / con nombre / públicas | [Renderizado](/docs/crema/rendering/#echo-helpers) |
| `{{ csrf_token() }}` / `{{ old(key) }}` | Token CSRF / entrada en flash | [Renderizado](/docs/crema/rendering/#echo-helpers) |
| `{{ env(key) }}` / `{{ config(key) }}` | Entorno / configuración | [Renderizado](/docs/crema/rendering/#echo-helpers) |
| `{{ trans(key) }}` / `{{ __(key) }}` / `{{ lang(key) }}` | Traducción | [Renderizado](/docs/crema/rendering/#echo-helpers) |
| `@@` | `@` literal | [Renderizado](/docs/crema/rendering/) |
| `{{-- … --}}` | Comentario (se elimina) | [Renderizado](/docs/crema/rendering/) |

## Layouts y secciones

| Directiva | Cierre / notas | Guía |
|-----------|----------------|-------|
| `@extends('layout')` | El hijo declara el layout padre | [Layouts](/docs/crema/layouts/) |
| `@section('name', 'text')` | Sección en línea | [Layouts](/docs/crema/layouts/) |
| `@section('name')` | Sección de bloque | `@endsection` o `@show` |
| `@endsection` | Cierra la sección de bloque (guarda crudo) | [Layouts](/docs/crema/layouts/) |
| `@show` | Cierra la sección y la expande de inmediato | [Layouts](/docs/crema/layouts/) |
| `@yield('name')` | Imprime la sección | Valor predeterminado opcional: `@yield('n', 'default')` |
| `@parent` | Inserta el búfer de la sección padre | Dentro de un `@section` hijo |
| `@hasSection('name')` | Cuerpo si la sección está definida | Cierra con `@endif` |
| `@sectionMissing('name')` | Cuerpo si falta la sección | Cierra con `@endif` |

`index`, `iteration`, `first`, `last`, `count`, `remaining`, `even`, `odd`, `depth`, `parent` — consulta [Metadatos del bucle](/docs/crema/control-structures/#loop-metadata).

## Componentes y slots

| Sintaxis | Propósito | Guía |
|--------|---------|-------|
| `@component('name')…@endcomponent` | Renderiza una vista como componente | [Componentes](/docs/crema/components/) |
| `@slot('name')…@endslot` | Slot con nombre dentro de `@component` | [Componentes](/docs/crema/components/) |
| `<x-name>…</x-name>` | Renderiza `components.name` | [Componentes](/docs/crema/components/) |
| `<x-name />` | Slot predeterminado vacío | [Componentes](/docs/crema/components/) |
| `<x-slot name="n">…</x-slot>` | Slot con nombre para `<x-*>` o etiquetas con prefijo | [Componentes](/docs/crema/components/) |
| `<x-slot:n>…</x-slot:n>` | Forma de nombre con dos puntos | [Componentes](/docs/crema/components/) |
| `<prefix:slot name="n">…` | Slot con nombre para etiquetas de extensión | [Componentes](/docs/crema/components/) |

Dentro de la vista del componente: `{{ slot }}` (predeterminado) y `{{ name }}` para cada slot con nombre.

## Extensiones propias

Las apps y los paquetes pueden registrar más sintaxis en `CremaEngine`:

| API | Forma |
|-----|-------|
| `directive(name) { … }` | `@name` / `@name(args)` |
| `blockDirective(name) { … }` | `@name…@endname` |
| `tag(prefix) { … }` | `<prefix:name>…` |

Wire las usa para `@brew` y `<wire:…>`. Consulta [Wire](/docs/wire/).
