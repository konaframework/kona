Inertia 2 props can be plain values or wrappers that change when they resolve and how the client merges them.

| Helper | Full visit | Partial visit | Page metadata |
|--------|------------|---------------|---------------|
| plain value / lambda | included | if selected | — |
| `Inertia.optional { }` | omitted | if selected | — |
| `Inertia.lazy { }` | same as optional (deprecated alias) | if selected | — |
| `Inertia.always(...)` | included | **always** | — |
| `Inertia.defer { }` | omitted; listed under `deferredProps` | if selected | `deferredProps` |
| `Inertia.merge(...)` | included | if selected | `mergeProps` |
| `Inertia.deepMerge(...)` | included | if selected | `deepMergeProps` |

Inertia.render(

## Deferred groups

Deferred props share a group name (default `"default"`). The client issues one partial reload per group after the first paint. Pass the group as the second argument to `Inertia.defer`.

## Merge / prepend / match

- `Inertia.merge(value)` → append on partial reload (`mergeProps`)
- `.prepend()` on a `MergeProp` / `DeferProp` → `prependProps`
- `Inertia.deepMerge(value)` → `deepMergeProps`
- `.matchOn("id")` → `matchPropsOn` entries like `results.id`
- `X-Inertia-Reset` drops merge metadata for those keys on that request
