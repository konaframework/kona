Usa esta guía cuando quieras un escritorio para quienes operan la app: encontrar un registro, cambiarlo y ver que se guardó. Escribe las pantallas en Kotlin o Java, ponlas junto al panel y abre `/admin`.

Firefly dibuja el HTML en el servidor. Los botones, los diálogos y los campos en vivo se quedan en el navegador a través de [Wire](/docs/wire/) y Alpine. Cuando añades una columna o un botón, lo añades en la clase.

Firefly se apoya en [Filament](https://filamentphp.com/). Usa un panel para el escritorio. Deja una página pública o una API JSON en una ruta Kona normal. Añadir el módulo no toca esas rutas. Las URLs aparecen cuando tu `Panel` llama a `mount`.

También puedes llamar a `render()` en un esquema, un formulario o una tabla y dejar ese HTML en una vista o en una prueba. El panel es lo que convierte esas piezas en URLs, una barra lateral y una pantalla de inicio de sesión.

## Qué pones en la app

Crea `app/firefly/Panel`. Extiende `org.konaframework.firefly.Panel`. `discover` lee tres carpetas junto a ese archivo:

| Carpeta | Pon esto aquí |
|--------|----------------|
| `pages/` | Una pantalla que diseñas, como la página Desk |
| `widgets/` | Una estadística, un gráfico o un bloque en una página |
| `resources/` | Una clase por tipo de registro, como notes u orders |

`samples/hello-kotlin` y `samples/hello-java` tienen esa disposición, montada en `/admin`. Estas páginas siguen el ejemplo de Kotlin. El ejemplo de Java tiene las mismas pantallas.

En esa app puedes abrir:

- `/` — la página de bienvenida, fuera del panel
- `/admin/desk` — la página Desk: un formulario, un infolist, una tabla, una acción de cabecera y un widget
- `/admin/notes/manage` — un recurso simple. Una página. Crear, editar, ver y borrar se abren en un diálogo
- `/admin/orders/list`, `/admin/orders/create`, `/admin/orders/edit`, `/admin/orders/view` — un recurso completo, con líneas en editar y ver

Deja un recurso en `resources/`. El descubrimiento lo recoge. Llama a `page`, `widget` o `resource` tú mismo solo cuando quieras saltarte la carpeta.

## Dónde viven los tipos

Depende de `org.konaframework:kona-firefly`. Esa coordenada trae los demás módulos de Firefly. Abre un módulo cuando quieras el paquete de un tipo:

- `kona-firefly` — el panel, las páginas, los recursos, la navegación, la tenencia, los plugins, la importación y la exportación, y `Firefly.test`
- `kona-firefly-schemas` — el árbol de componentes y su mapa de estado. Las secciones, las cuadrículas, las pestañas y el texto plano viven aquí
- `kona-firefly-forms` — campos en ese árbol, incluido el select de combobox y el selector de fecha propio, con validación
- `kona-firefly-infolists` — entradas de solo lectura: texto, iconos, imágenes y las otras formas de mostrar un registro
- `kona-firefly-tables` — columnas, filtros, búsqueda, orden y páginas
- `kona-firefly-actions` — un botón o un enlace, el diálogo que puede abrir y el método de servidor al que llama
- `kona-firefly-notifications` — un toast, una campana de base de datos y un marcador de refresco por broadcast
- `kona-firefly-widgets` — estadísticas, gráficos y bloques propios en una página
- `kona-firefly-support` — el diálogo, los iconos, los tokens de tema y `FireflyException`. Los otros módulos dependen de él, así que tu app solo depende de `kona-firefly`

## Cuando quieres un plugin, un tema o una prueba

Pasa un plugin a `plugin(...)`. `register` corre de inmediato. `boot` corre cuando el panel se monta. Dentro de esos métodos llamas a los mismos métodos del panel que llama la app: una marca, un hook, una página. Deja la clase en la app cuando el comportamiento pertenece a esa app. Lee [Plugins](/docs/firefly/plugins/).

El aspecto publicado es `KonaTheme`. `Stylesheet.render` escribe los colores y la tipografía como propiedades CSS personalizadas en `.ff-panel`. Las reglas de los componentes solo coinciden dentro de esa clase. Para cambiar el aspecto, implementa `FireflyTheme` y pásalo a `theme(...)`. `extraCss()` se envuelve en `.ff-panel { ... }`, así que tus reglas se quedan dentro del panel. El ejemplo hello usa el tema publicado. Lee [Temas y CSS](/docs/firefly/themes/).

`Firefly.test` lee HTML que ya renderizaste. Vive en `org.konaframework.firefly.testing`.

<TabItem label="Java">

Firefly.test(page)

`assertSee` falla cuando falta el texto. `assertFormField` busca `data-ff-path`. `assertTable` quiere tanto `ff-table` como el texto. `assertDialog` quiere tanto `ff-dialog` como el título. `Firefly.test(html)` comprueba una cadena. Las mismas afirmaciones están en [Importación y exportación](/docs/firefly/import-export/).

## Lee estas páginas en orden

1. [Requisitos](/docs/firefly/requirements/) — JDK 21 y la app Kona que ya tienes.
