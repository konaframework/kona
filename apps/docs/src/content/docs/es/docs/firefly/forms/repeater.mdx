`Repeater` edits a list of maps. Each item uses the same field blueprint. The field posts one JSON array under its name. Items support add, delete, clone, reorder, and collapse chrome.

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
Repeater.make("notes")
    .label("Notes")
    .schema(
        TextInput.make("title").label("Title").required(),
        Textarea.make("body").label("Body"),
    )
    .addable(true)
    .reorderable(true)
    .cloneable(true)
    .collapsible(true)
    .minItems(1)
    .maxItems(10)
    .defaultItems(1)
    .addActionLabel("Add note")
```

</TabItem>

`simple(field)` is a shortcut for a single-field schema.

## Options

| Method | Effect |
|--------|--------|
| `schema(...)` / `simple(field)` | Item blueprint |
| `addable` / `deletable` / `reorderable` / `cloneable` | Item controls (add/delete default `true`) |
| `collapsible` / `collapsed` | Collapse chrome; start collapsed when both on |
| `grid(count)` | Columns inside each item (`--ff-item-cols`; minimum 1) |
| `minItems` / `maxItems` / `defaultItems` | Counts (`defaultItems` seeds empty maps) |
| `orderColumn` | Write 1-based sort positions into each row |
| `relationship(name)` | Store relation name attribute (does not load records alone) |
| `itemLabel` | Fixed label or `(index, Get) -> String` |
| `addActionLabel` | Add button copy (default `"Add"`) |
| `addAction` / `deleteAction` / `cloneAction` / `extraItemActions` | Extra `Action`s rendered with items |
| `items` / `addItem` / `removeItem` / `cloneItem` / `moveItem` | Read / mutate schema state |

When `itemLabel` is unset, labels default to `Item 1`, `Item 2`, … and the template uses `Item {n}`.

## Validation

`extraErrors` enforces `minItems` / `maxItems`. Child fields marked `distinct()` reject duplicate non-empty values across items. Required children produce path errors like `notes.0.title`. Programmatic helpers (`addItem`, `removeItem`, `cloneItem`, `moveItem`) throw when an index is missing.

For typed heterogeneous blocks, use [`Builder`](/docs/firefly/forms/builder/). For flat string maps, use [`KeyValue`](/docs/firefly/forms/key-value/).

## Configure defaults

`Repeater.configureUsing { field -> ... }` runs for every new `make(...)` until you clear it with `configureUsing(null)`.
