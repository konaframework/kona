`HttpTestClient` resolves `HttpKernel` from a booted app and runs requests **in-process** (no listen socket). The client keeps a cookie jar and optional session across requests (Laravel HTTP tests shape).

## Create a client

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val http = HttpTestClient(app)
http.get("/ping").assertOk().assertJsonContains("ok")
```

</TabItem>
<TabItem label="Java">

```java
HttpTestClient http = new HttpTestClient(app);
http.get("/ping").assertOk().assertJsonContains("ok");
```

</TabItem>
</Tabs>

Register routes before calling the client (provider `boot`, or after `TestApplication.create`). For sessions and CSRF, register `SessionServiceProvider` and push `StartSession` (and usually `VerifyCsrfToken`) on the kernel the way your app's `bootstrap.Middleware` does.

## Builders

| Method | Notes |
| --- | --- |
| `withHeaders` / `withHeader` | Sent on every later request |
| `withCookies` / `withCookie` | Seed the cookie jar; `Set-Cookie` responses update it |
| `withSession` | Put values in the session before the next request (needs `kona-session`) |
| `actingAs(user)` / `actingAs(user, guard)` | Authenticate later requests; `actingAsGuest` clears |
| `followingRedirects` / `withoutFollowingRedirects` | Follow up to 10 redirect hops as `GET` |
| `withCsrfToken` / `withoutCsrfToken` | Auto `_token` + `X-CSRF-TOKEN` on state-changing verbs (default on) |

## Verbs

| Method | Notes |
| --- | --- |
| `get` / `delete` | Empty body; optional headers |
| `post` / `put` / `patch` / `delete(uri, formData, …)` | `application/x-www-form-urlencoded`; nested maps → `a[b]`, lists → `a[0]` |
| `postJson` / `putJson` / `patchJson` | Jackson JSON body |
| `put` / `patch` with a `String` body | Raw body |

When `kona-session` is registered, state-changing form requests get the session CSRF token unless you call `withoutCsrfToken()`.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
http.actingAs(cashier)
    .post("/pos/sales", mapOf("sku" to "A1", "qty" to "2"))
    .assertRedirect("/pos/receipt")

http.followingRedirects()
    .post("/login", mapOf("email" to "c@example.com", "password" to "secret"))
    .assertOk()
    .assertSee("POS")
```

</TabItem>
<TabItem label="Java">

```java
http.actingAs(cashier)
    .post("/pos/sales", Map.of("sku", "A1", "qty", "2"))
    .assertRedirect("/pos/receipt");
```

</TabItem>

## Response assertions

Every verb returns a `TestResponse` (fluent — assertions return `this`).

| Method | Behavior |
| --- | --- |
| `status()` / `body()` / `header` / `location` / `cookies` / `session` | Raw values |
| `assertStatus` / `assertOk` / `assertCreated` / `assertNoContent` | Exact / common statuses |
| `assertSuccessful` | 2xx |
| `assertUnauthorized` / `assertForbidden` / `assertNotFound` / `assertUnprocessable` | 401 / 403 / 404 / 422 |
| `assertRedirect` / `assertRedirect(uri)` / `assertRedirectToRoute` | 3xx + Location |
| `assertSee` / `assertSeeInOrder` / `assertDontSee` | Body text |
| `assertJsonContains` / `assertJsonPath` / `assertJson` | JSON body |
| `assertHeader` / `assertHeaderMissing` | Response headers |
| `assertCookie` / `assertCookieMissing` / `assertCookieExpired` | `Set-Cookie` |
| `assertSessionHas` / `assertSessionMissing` / `assertSessionHasErrors` / `assertSessionHasNoErrors` | Session (needs `StartSession`) |
| `assertValid` / `assertInvalid` | Session errors or JSON 422 `errors` |
| `assertInertia { … }` / `inertia()` | Inertia page (`X-Inertia` JSON or HTML `data-page`) |

### Inertia

```kotlin
http.get("/pos").assertInertia {
    component("Pos/Register")
    has("cart.lines", 2)
    where("title", "POS")
}
```

Paths are rooted at `props`. Java callers chain `response.inertia().component("…").has("cart.lines", 2)`.

## Edge cases

- Middleware on the kernel runs normally — CSRF, session, and auth behave as in production when those providers are registered.
- Bodies for non-JSON `put`/`patch` are raw strings; use the form overloads for `application/x-www-form-urlencoded`.
- Prefer [`@KonaTest`](./feature/) to boot the app's own `bootstrap.App` under `APP_ENV=testing`.
