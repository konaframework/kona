`KeyValue` edits a map of strings. The field posts one JSON object. Each pair is a row with key and value inputs, optional reorder controls, and a remove button.

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
KeyValue.make("meta")
    .label("Meta")
    .keyLabel("Key")
    .valueLabel("Value")
    .addActionLabel("Add row")
    .reorderable(true)
```

</TabItem>
<TabItem label="Java">

```java
KeyValue.make("meta")
    .label("Meta")
    .keyLabel("Key")
    .valueLabel("Value")
    .addActionLabel("Add row")
    .reorderable(true);
```

</TabItem>
</Tabs>

## Options

| Method | Effect |
|--------|--------|
| `keyLabel` / `valueLabel` | Header labels (string or `Get` closure; defaults `"Key"` / `"Value"`) |
| `keyPlaceholder` / `valuePlaceholder` | Input placeholders (fall back to the labels) |
| `addActionLabel` | Add-button label (default `"Add row"`) |
| `addable` / `deletable` | Show add / remove (default `true`) |
| `editableKeys` / `editableValues` | When `false`, key or value inputs are `readonly` (default `true`) |
| `reorderable(on)` | Move up / down buttons |
| `pairs(raw)` | Decode stored JSON into `List<Pair<String, String>>` |

Non-map stored values decode to an empty pair list. Only string keys are kept.

    .valueLabel("Value")
    .keyPlaceholder("X-Custom")

## Interaction

The add button appends an empty row from a `<template>`. Delete removes a row. Reorder moves a row up or down. The hidden input always holds the full JSON map.

For nested field schemas per item, use [`Repeater`](/docs/firefly/forms/repeater/). For typed block lists, use [`Builder`](/docs/firefly/forms/builder/).

## Configure defaults

`KeyValue.configureUsing { field -> ... }` runs for every new `make(...)` until you clear it with `configureUsing(null)`.
