`MarkdownEditor` is a Write | Preview pair. Write is a textarea; Preview renders GitHub-flavored markdown through `MarkdownHtml.render` into the preview pane. The footer notes that markdown is supported.

<FireflyShot file="form-markdown-editor.png" description="MarkdownEditor markdown field on the Playground form." />

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
MarkdownEditor.make("markdown")
    .label("Notes")
    .toolbarButtons("heading", "bold", "italic", "link", "list")
    .fileAttachmentsDisk("local")
    .fileAttachmentsDirectory("md")
```

</TabItem>

## Options

| Method | Effect |
|--------|--------|
| `toolbarButtons(...)` | Replace the tool list |
| `disableToolbarButtons(...)` | Hide tools by name |
| `fileAttachmentsDisk` / `fileAttachmentsDirectory` | Attachment storage (string or `Get` closure) |
| `preview(source)` | Render markdown source to HTML |

Default tools: `heading`, `bold`, `italic`, `strike`, `quote`, `code`, `link`, `image`, `list`, `ordered`. Extra glyphs exist for `task` and `table` when you add them to the toolbar.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
MarkdownEditor.make("readme")
    .label("README")
    .placeholder("Write markdown…")
    .toolbarButtons(
        "heading", "bold", "italic", "strike",
        "quote", "code", "link", "image",
        "list", "ordered", "task", "table",
    )
    .disableToolbarButtons("table")
    .fileAttachmentsDisk {{ get -> "local" }}
    .fileAttachmentsDirectory("uploads/md")

val html = MarkdownEditor.make("tmp").preview("# Hello")
```

</TabItem>

## Write and preview

The Write tab owns the posted `<textarea>`. Switching to Preview hides the textarea and shows HTML from `preview(...)`. Toolbar buttons insert formatting into the write surface. Attachment disk / directory attributes are exposed as `data-ff-disk` and `data-ff-directory` for the client uploader.

For WYSIWYG HTML, use [`RichEditor`](/docs/firefly/forms/rich-editor/). For highlighted source without markdown semantics, use [`CodeEditor`](/docs/firefly/forms/code-editor/).

## Configure defaults

`MarkdownEditor.configureUsing { field -> ... }` runs for every new `make(...)` until you clear it with `configureUsing(null)`.
