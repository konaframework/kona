`RichEditor` is a rich-text surface with a grouped toolbar. The default storage is sanitized HTML; call `json()` to store JSON instead. The panel loads the editor script from `/_firefly/rich-editor/simple.js`.

## Options

| Method | Effect |
|--------|--------|
| `toolbarButtons(groups)` | Replace default button groups (`List<List<String>>`) |
| `disableToolbarButtons(...)` | Hide tools by name |
| `json()` / `html()` | Storage mode (`json` skips HTML sanitizer) |
| `resizable(on)` | Resize handle |
| `fileAttachmentsDisk` / `Directory` / `Visibility` | Attachment storage (string or `Get`) |
| `mergeTags(...)` | Insertable merge tags (`data-ff-merge`) |
| `mentions(...)` / `mentions(provider)` | Static list or search function |
| `mention(query)` | Resolve mentions for a query |
| `customBlocks(EditorBlock...)` | Named blocks with nested schemas |
| `editBlockAction(name, action)` | Action beside a block dialog |
| `sanitize(html)` | Clean HTML when not in JSON mode |

Default toolbar groups:

1. `undo`, `redo`
2. `bold`, `italic`, `underline`, `strike`, `subscript`, `superscript`, `highlight`
3. `h1`, `h2`, `h3`
4. `align-left`, `align-center`, `align-right`, `align-justify`
5. `bullet`, `ordered`, `blockquote`, `code`
6. `link`, `image`, `table`

## Mentions and blocks

`mentions(vararg)` filters case-insensitively on `mention(query)`. `mentions(Function)` replaces that list with a custom provider. Custom blocks render a dialog per `EditorBlock`; `editBlockAction` attaches an extra `Action` for a named block.

## Configure defaults

`RichEditor.configureUsing { field -> ... }` runs for every new `make(...)` until you clear it with `configureUsing(null)`.
