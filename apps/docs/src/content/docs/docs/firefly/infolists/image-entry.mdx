`ImageEntry` renders `<img>` tags from string URLs (or a collection of them). It inherits every helper on [Entry](/docs/firefly/infolists/#helpers-on-every-entry). Use it for avatars, product photos, and small galleries on a view page.

<FireflyShot file="infolist-image-entry.png" description="An image entry showing a circular avatar." />

## Make an image entry

Set size, shape, alt text, and an optional fallback URL when state is blank.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
ImageEntry.make("photo")
    .label("Avatar")
    .circular(true)
    .size(64)
    .alt("Profile photo")
    .defaultImageUrl("/images/avatar.png")
    .state("/uploads/ada.png")
```

</TabItem>
<TabItem label="Java">

```java
ImageEntry.make("photo")
    .label("Avatar")
    .circular(true)
    .size(64)
    .alt("Profile photo")
    .defaultImageUrl("/images/avatar.png")
    .state("/uploads/ada.png");
```

</TabItem>
</Tabs>

Each image is `img.ff-image` inside `div.ff-images`. Shared `url` / `openUrlInNewTab` wrap each `<img>` in a link.

## Size and shape

| Method | Effect |
|--------|--------|
| `height` / `imageHeight` | Height as `Int` pixels or a CSS length string |
| `width` / `imageWidth` | Width as `Int` pixels or a CSS length string |
| `size` / `imageSize` | Sets height and width together |
| `circular(true)` | Adds `data-ff-circular` (round crop in CSS) |
| `square(true)` | Adds `data-ff-square` |
| `alt(text)` | Accessibility text on every `<img>` |
| `defaultImageUrl(url)` | Used when state is blank or an item is empty |
| `extraImgAttributes(map)` | Merged onto each `<img>` |

`Int` overloads append `px`. Closures (`Function<Get, String>` / `Predicate<Get>`) work on the same setters.

## Stacks and limits

| Method | Effect |
|--------|--------|
| `stacked(true)` | Stacked gallery flag (`data-ff-stacked`) |
| `overlap(n)` | Overlap amount (`data-ff-overlap`) |
| `ring(...)` | Ring token or CSS length (`data-ff-ring`) |
| `limit(n)` | Show at most `n` sources |
| `limitedRemainingText(true)` | Append `+N` for the hidden count |
| `limitedRemainingTextSeparate` | Style the remainder as a separate chip |
| `limitedRemainingTextSize` | Remainder size: `xs` … `xl` (aliases `small` → `sm`, …) |

<Tabs syncKey="lang">

ImageEntry.make("gallery")
    .stacked(true)
    .overlap(8)
    .ring(2)
    .size(40)
    .limit(3)
    .limitedRemainingText(true)
    .limitedRemainingTextSize("sm")
    .state(listOf("/a.png", "/b.png", "/c.png", "/d.png"))

## Disk attributes

| Method | Effect |
|--------|--------|
| `disk(name)` | Emitted as `data-ff-disk` |
| `visibility(value)` | Emitted as `data-ff-visibility` |
| `checkFileExistence(on)` | Default `true`; blank sources are dropped |

This module does not open a disk or sign a temporary URL. A relative or absolute URL string is rendered as `src`. Panel or storage layers may read the data attributes later; the entry itself only paints what you pass.

## Defaults for every make

`ImageEntry.configureUsing { entry -> entry.circular(true).size(48) }` runs for every later `make()`. Pass `null` to clear it.
