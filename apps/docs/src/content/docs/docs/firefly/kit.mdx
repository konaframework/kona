---
title: Tenancy, plugins, and import
description: "Jump to the page that adds a tenant menu, a plugin, or a CSV import. The kit itself is installed on the Installation page."
---

Open the page for the job you are doing. Each one is a separate step on the panel you already mounted.

- [Tenancy](/docs/firefly/tenancy/) adds the tenant menu and `Resource.tenant`, so a resource filters rows for the selected tenant.
- [Plugins](/docs/firefly/plugins/) is a class you pass to `plugin(...)`. `register` runs immediately. `boot` runs when the panel mounts.
- [Import and export](/docs/firefly/import-export/) writes and reads CSV through a dialog action and a queue job, and shows `Firefly.test` on a rendered page.

`kona new desk --kit=firefly` is the install path. Follow it on [Installation](/docs/firefly/installation/).
