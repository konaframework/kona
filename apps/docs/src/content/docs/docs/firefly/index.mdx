**Kona Firefly** (short name **Firefly**) is Kona’s application-panel product. A panel is a themed shell — sidebar, top bar, body, and footer — plus dialogs that actions can open. Firefly renders that chrome on the server and keeps interactive pieces on [Wire](/docs/wire/) and Alpine.

(Brief nod: Firefly occupies the same problem space as full application-panel kits. The rest of these pages describe Firefly on its own terms.)

Two artifacts are in the repository today.

`org.konaframework:kona-firefly-support`, package `org.konaframework.firefly.support`, gives you themes, scoped CSS, panel chrome, render hooks, icons, and the shared dialog. It does not register HTTP routes, middleware, or views. Adding it to an existing application does not change routes you already defined.

`org.konaframework:kona-firefly-schemas`, package `org.konaframework.firefly.schemas`, builds the schema tree: layouts, text, icons, images, state, and live updates. Read [Schemas](/docs/firefly/schemas/) for that API. Tables, navigation trees, and mounted panel routes are not in these artifacts yet.

## Add the module

Depend on the Firefly modules through the Kona BOM (`org.konaframework`). The first Firefly release train is **0.4.x**. Until that train is published, use the modules from a Kona checkout:

```kotlin
dependencies {
    implementation(project(":kona-firefly-support"))
    implementation(project(":kona-firefly-schemas"))
}
```

Java projects use the same coordinates. Every public type in this package is callable from Java.

## What you build with

| Type | Role |
|------|------|
| [`FireflyTheme`](/docs/firefly/themes/) | Colors, font, radius, and optional replacement HTML for a chrome slot |
| [`KonaTheme`](/docs/firefly/themes/) | Built-in caramel theme (`id` is `kona`) |
| [`Stylesheet`](/docs/firefly/themes/) | Turns a theme into CSS variables scoped under `.ff-panel` |
| [`PanelShell`](/docs/firefly/chrome/) | Picks the theme, layout, hooks, and partial overrides, then renders |
| [`Dialog`](/docs/firefly/dialog/) | One dialog component: modal, sidebar, or fullscreen |
| `Icon` | Inline SVG icons: `HOME`, `BARS`, `USER`, `X` |
| `FireflyException` | Unchecked failure for a bad width, a missing hook marker, or CSS that escapes the panel |

## A shell in one call

Kotlin:

```kotlin
val html = PanelShell()
    .theme(KonaTheme())
    .hook(Hook.BODY_START, "<p>Welcome</p>")
    .render()
```

Java:

```java
String html = new PanelShell()
    .theme(new KonaTheme())
    .hook(Hook.BODY_START, "<p>Welcome</p>")
    .render();
```

`render()` returns one root `<div class="ff-panel">` with a `<style>` block, then the sidebar, top bar, body, and footer. The body partial contains the hook text `Welcome`.

## Icons

`Icon.HOME`, `Icon.BARS`, `Icon.USER`, and `Icon.X` each expose `path` and `svg()`. `svg()` returns an `<svg class="ff-icon">` whose path data is HTML-escaped.

`Icon.fromName` accepts those names in any letter case (`"HoMe"` is `HOME`). Any other name throws `FireflyException` with the message `Unknown icon [<name>]`.

```kotlin
Icon.fromName("bars").svg()
```

```java
Icon.fromName("bars").svg();
```

## Failure type

`FireflyException` extends `RuntimeException`. Callers do not have to declare it. The message names the bad value: the dialog width, the theme id, the partial slot, or the icon name.
