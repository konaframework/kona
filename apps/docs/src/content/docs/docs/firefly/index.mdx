**Kona Firefly** (short name **Firefly**) is Kona’s panel for the people who run an application. A **panel** is one signed-in (or public) area of the site: a brand, a navigation tree, and the screens that list and edit records. Firefly draws that area on the server. Buttons, dialogs, and live fields stay in the browser through [Wire](/docs/wire/) and Alpine.

You use Firefly when the work is “open the desk, find the order, change it, and see that it saved” — not when the work is a public marketing page or a JSON API. Those stay on ordinary Kona routes. Adding the Firefly module does not rewrite routes you already defined. Routes appear when a `Panel` calls `mount`.

## What you build

A panel is a class named `Panel` in `app/firefly`. It discovers three folders next to itself:

| Folder | What lands there |
|--------|------------------|
| `pages/` | Screens you design yourself, such as a desk |
| `widgets/` | Stats, charts, and other cards placed on a page |
| `resources/` | One class per record type, such as notes or orders |

The hello samples (`samples/hello-kotlin` and `samples/hello-java`) are that layout, mounted at `/admin`. The same samples are the app these guides follow.

## How to read the rest

Follow the sidebar from top to bottom the first time:

1. [Requirements](/docs/firefly/requirements/) — JDK and the Kona app you already have.
2. [Installation](/docs/firefly/installation/) — `kona new --kit=firefly`, or add the module to an existing app.
3. [Register a panel](/docs/firefly/registration/) — the `Panel` file, the folders, and `discover`.
4. [A working app](/docs/firefly/working-app/) — a simple notes resource and a full orders resource.

After that, each component has its own page: what it is, how a request uses it, the methods that exist, and Kotlin and Java examples. Start with [Panel](/docs/firefly/panel/) when you are ready to leave the walkthrough.

Kotlin and Java call the same types. Every example that matters is shown in both languages. The class you extend is `Panel`. The package is `org.konaframework.firefly`.
