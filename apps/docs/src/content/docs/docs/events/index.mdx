import { Tabs, TabItem } from '@astrojs/starlight/components';

Kona’s event bus is a small synchronous dispatcher. Register listeners (Kotlin lambdas or Java SAMs), then `dispatch` typed event objects.

## Quick start

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
data class OrderShipped(val id: String)

val bus = EventDispatcher()
bus.listen(OrderShipped::class.java) { println(it.id) }
bus.dispatch(OrderShipped("42"))
```

</TabItem>
<TabItem label="Java">

```java
bus.listen(OrderShipped.class, event -> System.out.println(event.id));
bus.dispatch(new OrderShipped("42"));
```

</TabItem>
</Tabs>

Register `EventServiceProvider` to bind `EventDispatcher` in the container.

## API

- `listen(Class, EventListener)` / Kotlin `listen { }`
- `dispatch(event)`
- `forget(Class)` / `flush()`
- `hasListeners` / `listenerCount`
