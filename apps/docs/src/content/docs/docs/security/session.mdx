## What a session is

A session stores data across requests for one browser (or client) under a session id. Kona attaches the session to the request as attribute `"session"` via the `StartSession` middleware.

## Drivers

Configure with `session.driver`:

| Driver | Behavior |
|--------|----------|
| `array` / `memory` | In-process map (tests / single process) |
| `file` | JSON files under `storage/framework/sessions` (or `session.files`) |
| `cookie` | Base64 JSON payload in the session cookie (unsigned in M3 — encrypt later) |

Other keys: `session.lifetime` (minutes), `session.cookie`, `session.path`, `session.secure`, `session.http_only`, `session.same_site`.

## Usage

```kotlin
val session = request.getAttribute(StartSession.ATTRIBUTE) as Session
session.put("user_id", 1)
session.flash("status", "Saved")
```

```java
Session session = (Session) request.getAttribute(StartSession.ATTRIBUTE);
session.put("user_id", 1);
session.flash("status", "Saved");
```

Register `SessionServiceProvider`, resolve `SessionManager`, and add `StartSession(manager)` to the kernel.
