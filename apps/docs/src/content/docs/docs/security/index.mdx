Kona’s security stack ships in two modules:

- **`kona-session`** — HTTP sessions (array/file/cookie drivers), flash data, and CSRF verification.
- **`kona-auth`** — hashing, guards, password resets, gates/policies, API tokens, encryption, CORS, security headers, and rate limiting.

## Simple path

Apps from `kona new` already register session and auth providers and wire `StartSession` + CSRF in `bootstrap.Middleware`.

1. Keep `SessionServiceProvider` and `AuthServiceProvider` on the bootstrap provider list (scaffolded by default).
2. Keep `StartSession` and `VerifyCsrfToken` on the web stack (`/api/*` is CSRF-excepted).
3. Use `AuthManager` / session attributes in controllers.

Later pages dig into each piece.
