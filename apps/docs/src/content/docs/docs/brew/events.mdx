---
title: Brew browser events
description: Listen to DOM and custom events with wire:* modifiers.
---

Brew treats **browser events** as first-class triggers for actions. Use `wire:<event-name>` on any element. Component-to-component `dispatch` / `@On` and the JavaScript `Brew.dispatch*` helpers land in a later guide; this page covers what ships with the core runtime.

## Click and friends

```html
<button wire:click="save">Save</button>
<button wire:click.prevent="save">Save</button>
<button wire:dblclick="edit">Edit</button>
```

## Keyboard

```html
<input wire:keydown.enter="search" />
<input wire:keydown.shift.enter="newline" />
<div wire:keydown.escape.window="close"></div>
```

Key modifiers include `.enter`, `.escape`, `.space`, `.tab`, `.shift`, `.ctrl`, `.alt`, `.meta` / `.cmd`, arrow keys, `.page-up` / `.page-down`, and `.slash`.

## Scope and timing modifiers

| Modifier | Role |
|----------|------|
| `.window` / `.document` | Listen on window / document |
| `.outside` | Fire when the event happens outside the element |
| `.self` | Only when the event target is the element |
| `.once` | Remove listener after first fire |
| `.debounce.Xms` / `.throttle.Xms` | Rate-limit |
| `.passive` / `.capture` | AddEventListener options |
| `.camel` / `.dot` | Event name casing |

## Custom / third-party events

```html
<div wire:trix-change="updated"></div>
<div wire:custom-event="onCustom"></div>
```

Any DOM event name works after `wire:`.

## Init

```html
<div wire:init="load">…</div>
```

Runs once when the component element is initialized on the client.
