**Brew** is Kona’s reactive server-component layer. You write Kotlin or Java classes with public state and actions, render HTML with [Crema](/docs/crema/), and Brew keeps the browser in sync over a small JSON protocol—without a full page reload.

Brew ships as `org.konaframework:kona-brew` on [Maven Central](https://repo1.maven.org/maven2/org/konaframework/kona-brew/). Scaffold with `kona new my-app --kit=brew`, or add the dependency with `./grind install brew` (or `kona grind install brew`).
