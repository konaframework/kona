**Brew** is Kona’s reactive server-component layer. You write Kotlin or Java classes with public state and actions, render HTML with [Crema](/docs/crema/), and Brew keeps the browser in sync over a small JSON protocol—without a full page reload.

Brew ships as a separate artifact (`org.konaframework:kona-brew`) from the [kona-brew](https://github.com/konaframework/kona-brew) repository. Scaffold with `kona new my-app --kit=brew`, or add the dependency next to your other Kona modules.

## Full documentation

Guides for components, properties, actions, forms, nesting, uploads, JavaScript, testing, and more live on the Brew docs site:
