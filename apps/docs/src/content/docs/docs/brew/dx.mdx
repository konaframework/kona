## Scaffolding

```bash
./grind make:brew posts.create-post
./grind make:brew pages::Dashboard --class --test
./grind make:brew Avatar --mfc --emoji
./grind make:brew Counter --lang=java
```

Default type comes from `brew.make.type` (`sfc` | `class` | `mfc`). Customize stubs with `./grind brew:stubs`, then edit `stubs/brew/*`.

## Convert / publish / layout

```bash
./grind brew:convert src/main/kotlin/app/brew/Counter.kt --to=class
./grind brew:convert … --to=sfc
./grind brew:convert … --to=mfc
./grind brew:publish --config
./grind brew:layout
```

## Testing helpers

```kotlin
Brew.test("counter")
    .actingAs(user)
    .withQueryParams(mapOf("q" to "1"))
    .withCookie("a", "1")
    .withHeaders(mapOf("X-Test" to "yes"))
    .withoutLazyLoading()
    .call("save")
    .assertJs("alert")
    .assertRedirectTo("/next")
    .assertHasErrors("email")
```
