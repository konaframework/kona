grind (and the global `kona` CLI) use Termwind-inspired console styling: brand colors (`#FF9A00` / `#286291`), success/info/warn/error markers, boxes, two-column lists, and progress bars via `GrindIO`.

| Env | Effect |
| --- | --- |
| `NO_COLOR` | Disable ANSI (any value) |
| `FORCE_COLOR=1` | Force ANSI even when `TERM=dumb` |
| `FORCE_COLOR=0` | Keep color off |

## Global flags

| Flag | Effect |
| --- | --- |
| `-v` / `--verbose` | Extra diagnostics from commands that use `GrindIO.verbose` |
| `-q` / `--quiet` | Suppress normal stdout (`list`, schedule messages, …) |

Exit code `0` means success; `1` means usage errors, missing projects, or unbound services.

## list

```bash
./grind list
```

Prints every grind command in a two-column, colored summary.

## Prompts

Use `Prompts` inside custom commands (injectable streams for tests):

```kotlin
val prompts = Prompts()
val name = prompts.ask("Name", default = "Kona")
val ok = prompts.confirm("Continue?")
val pick = prompts.choice("Driver", listOf("array", "redis"))
```
