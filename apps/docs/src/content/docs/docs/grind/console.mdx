All Kona terminal CLIs share one Termwind-inspired console style: brand colors (`#FF9A00` / `#286291`), success/info/warn/error markers, boxes, two-column lists, tables, and progress bars.

| API | Where |
| --- | --- |
| `dev.kona.support.console.ConsoleIO` | Canonical implementation (`kona-support`) |
| `GrindIO` | `./grind` — wraps `ConsoleIO` with `-q` / `-v` |
| Helpers on `ConsoleCommand` | `info`, `success`, `warn`, `error`, `table`, `progress`, … |

Do not print to the terminal with raw `println` in commands; use these APIs.

| Env | Effect |
| --- | --- |
| `NO_COLOR` | Disable ANSI (any value) |
| `FORCE_COLOR=1` | Force ANSI even when `TERM=dumb` |
| `FORCE_COLOR=0` | Keep color off |

## Global flags

| Flag | Effect |
| --- | --- |
| `-v` / `--verbose` | Extra diagnostics from commands that use `GrindIO.verbose` |
| `-q` / `--quiet` | Suppress normal stdout (`list`, schedule messages, …). Errors still print. |

## Output helpers

Inside a `ConsoleCommand`, prefer the helpers (they respect quiet/verbose via the bound `GrindIO`):

```kotlin
info("Working…")
success("Done")
warn("Slow path")
error("Could not connect")
title("Report")
table(
    listOf("id", "email"),
    listOf(listOf("1", "ada@example.com"), listOf("2", "bea@example.com")),
)
progress(3, 10, "users")
verbose("only with -v")
```

`ConsoleIO.table` / `GrindIO.table` align columns by plain-text width (ANSI codes ignored for padding).

## Prompts

Use `Prompts` for interactive input (injectable streams keep tests non-interactive):

```kotlin
val prompts = Prompts()
val name = prompts.ask("Name", default = "Kona")
val ok = prompts.confirm("Continue?")
val pick = prompts.choice("Driver", listOf("array", "redis"))
```

| Method | Behavior |
|--------|----------|
| `ask` | Free text; empty line uses `default` when set |
| `confirm` | `y`/`yes` vs default `Y/n` or `y/N` |
| `choice` | Numbered list; accepts index or case-insensitive label |

## Exit codes

| Code | Constant | Meaning |
|------|----------|---------|
| `0` | `ConsoleCommand.SUCCESS` | Success (also used when `--isolated` skips a busy command) |
| `1` | `ConsoleCommand.FAILURE` | Usage errors, missing projects, failed generators, unbound services |

Scripts and CI should treat any non-zero exit as failure.
