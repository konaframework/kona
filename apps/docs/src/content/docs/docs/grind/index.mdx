---
title: grind
description: Kona’s command-line tool for scaffolding, serving, and generating code.
---

**grind** is the terminal entry point for day-to-day Kona work. You use it to create projects, start the HTTP server against a real app, and generate boilerplate such as controllers.

Today grind ships with:

- [`grind new`](./commands/#grind-new) — create a Kotlin or Java Gradle application
- [`grind serve`](./commands/#grind-serve) — run that application
- [`grind make:controller`](./commands/#grind-makecontroller) — add a controller class

Later releases add more generators, database commands, and **steam** (an interactive shell inside a booted application).

Run `grind --help` (or `./gradlew :kona-grind:run --args="--help"` from the framework repo) to see the installed commands on your build.
