---
title: grind
description: Kona CLI — scaffold, serve, and generate code.
---

**grind** is Kona’s Artisan / `smith` equivalent. M1 ships:

- `grind new` — scaffold a Kotlin or Java Gradle app
- `grind serve` — run the app in the current project
- `grind make:controller` — generate a controller class

Later milestones add `make:model`, `migrate`, `steam`, and more.

See [commands](./commands/).
