title: Kotlin and Java
description: Use the same Kona APIs from Kotlin and Java without second-class call sites.
---

Kona’s implementation language is Kotlin. That does **not** mean Java apps are an afterthought. Public types expose `@JvmStatic` factories, `@JvmOverloads` constructors, and SAM interfaces so Java lambdas and method references work the way you expect.

When these docs show both languages, the behavior is the same; only the call syntax differs.

## Handlers

HTTP actions implement `Handler` — a single-abstract-method type: `handle(Request): Response`.

**Kotlin** can use a trailing lambda anywhere a `Handler` is expected:

```kotlin
router.get("/ping") { request -> Response.text("pong") }
```

**Java** uses a lambda or method reference:

```java
router.get("/ping", request -> Response.text("pong"));
```

## Route groups

Groups apply a URL prefix, an optional name prefix for named routes, and middleware to every route registered inside the block.

**Kotlin** — DSL receiver:

```kotlin
router.group(prefix = "/api", name = "api.", middleware = listOf(requireToken)) {
    get("/me") { Response.json(mapOf("ok" to true)) }
}
```

**Java** — fluent chain then `group(Consumer)`:

```java
router.prefix("/api").name("api.").middleware(requireToken).group(api -> {
    api.get("/me", req -> Response.json(Map.of("ok", true)));
});
```

There are also overloads such as `group(prefix, middleware, consumer)` if you prefer not to use the fluent builder.

## Middleware

`Middleware` receives the current `Request` and a `next` `Handler`. Call `next.handle(request)` (Java) or `next(request)` (Kotlin extension) to continue the pipeline. Returning without calling `next` short-circuits the chain.

## Application builder

```kotlin
Kona.create(args)
    .providers(HttpServiceProvider(), AppServiceProvider())
    .configure { config -> config.set("app.name", "Demo") }
    .boot()
```

```java
Kona.create(args)
    .providers(new HttpServiceProvider(), new AppServiceProvider())
    .configure(config -> config.set("app.name", "Demo"))
    .boot();
```
