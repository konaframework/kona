## Prerequisites

- JDK 21+
- Global `kona` on your PATH ([Installation](../installation/))

## Create the project

```bash
kona new hello-kona
cd hello-kona
```

Use `--lang=java` for a Java skeleton. `kona new` refuses to overwrite an existing directory.

You should see something like:

```text
Created Kona application at …/hello-kona (kotlin)
  cd hello-kona
  ./grind serve
```

## What you got

| Path | Role |
|------|------|
| `./grind` | **App-local** CLI (serve, make:controller) |
| `./gradlew` | Gradle wrapper — builds and runs the app |
| `bootstrap/App` | Boots Kona, registers providers, starts HTTP |
| `app/Providers/` | Your service provider |
| `app/Http/Controllers/` | Controllers |
| `routes/` | Route table |
| `.env` | `APP_NAME`, `APP_DEBUG`, `HOST`, `PORT` |
| `build.gradle.kts` | Depends on `kona-http` and `kona-grind` |

`kona` itself is **not** copied into the project. Only `./grind` is local.

## Serve

```bash
./grind serve
```

Open `http://127.0.0.1:8080/` (or the `HOST`/`PORT` from `.env`). Stop with Ctrl+C.

Under the hood, `./grind serve` runs `./gradlew run` so the app compiles with its own dependencies. For tests you can use `./grind serve --in-process` after `./gradlew classes`.

## Add a controller

```bash
./grind make:controller Post
```

Then register a route in `routes/` that uses it.

## Create another app later

Stay global — do not use grind for this:

```bash
cd ..
kona new shop --lang=java
cd shop
./grind serve
```
