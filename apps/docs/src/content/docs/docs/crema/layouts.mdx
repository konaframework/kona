---
title: Layouts
description: Build page layouts with @extends, @section, @yield, @parent, and section checks.
---

Layouts let child views fill named regions of a shared shell (HTML document, admin chrome, and so on).

## Parent layout

```crema
{{-- layouts/app.crema.html --}}
<html>
  <title>@yield('title', 'App')</title>
  <body>
    @hasSection('sidebar')
      <aside>@yield('sidebar')</aside>
    @endif
    @sectionMissing('sidebar')
      <aside>Default sidebar</aside>
    @endif
    @yield('content')
    @stack('scripts')
  </body>
</html>
```

`@yield('name')` prints the section named `name`. A second argument is the default when the child did not define the section.

`@hasSection('name')…@endif` and `@sectionMissing('name')…@endif` are conditionals that check whether a section was defined for this render.

## Child view

```crema
{{-- home.crema.html --}}
@extends('layouts.app')
@section('title', 'Home')
@section('content')
  Hello {{ name }}
@endsection
```

`@extends('layouts.app')` must appear in the child. Sections can be:

- Inline: `@section('title', 'Home')`
- Block: `@section('content') … @endsection`
- Immediate show: `@section('s')…@show` (expands then stores)

## `@parent`

When a child redefines a section that the parent also filled, use `@parent` inside the child section to keep the parent’s text:

```crema
{{-- parent defines section content = PARENT --}}
@section('content')
  CHILD @parent MORE
@endsection
{{-- yields: CHILD PARENT MORE --}}
```

Crema stores the earlier section body as the parent buffer and replaces `@parent` when the section is yielded.
