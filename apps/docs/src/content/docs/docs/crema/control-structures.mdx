## Conditionals

```crema
@if(n == 1)
  One
@elseif(n == 2)
  Two
@else
  Other
@endif

@unless(ok)
  Hidden when ok is truthy
@endunless

@isset(name)
  Name is present
@endisset

@empty(items)
  No items
@endempty
```

Truthy values: non-null, non-false, non-zero numbers, non-empty strings/collections/maps/arrays.

`@isset(expr)` is true when the resolved value is non-null. `@empty(expr)` is true when the value is not truthy (same idea as the `empty()` expression helper).

## `@while`

```crema
@while(loop.iteration <= n)
  {{ loop.iteration }}
@endwhile
```

Each pass injects a `loop` map (`index`, `iteration`, …) into a child context before evaluating the condition. Cap is 10 000 iterations as a safety limit.

## `@foreach` / `@each` / `@for`

Collection form (all three share the same loop helpers):

```crema
@foreach(items as item)
  <li>{{ item }} ({{ loop.iteration }})</li>
@endforeach
```

`@each` / `@endeach` and `@for(items as item)…@endfor` behave the same.

### Range and C-style `@for`

```crema
@for(i in 0..2)
  {{ i }}
@endfor

@for(i = 0; i < n; i++)
  {{ i }}
@endfor
```

`0..2` is inclusive. The C-style form uses a strict `<` upper bound.

### Loop metadata

| Key | Meaning |
|-----|---------|
| `index` | Zero-based index |
| `iteration` | One-based index |
| `first` / `last` | Booleans |
| `count` | Total size |
| `remaining` | Items after this one |
| `even` / `odd` | Based on zero-based index |
| `depth` | Nesting depth (1 at the outermost loop) |
| `parent` | Outer loop map when nested, else null |

`@forelse` uses the same loop map as `@foreach`.

## `@forelse`

```crema
@forelse(items as item)
  {{ item }}
@empty
  None
@endforelse
```

## Auth and guest

```crema
@auth
  Signed in
@endauth

@guest
  Please sign in
@endguest
```

A visitor is treated as authenticated when the view data has any of:

- `__authenticated` truthy
- `auth_user` non-null
- `user` non-null

## Abilities

```crema
@can('edit')
  Edit button
@endcan

@cannot('edit')
  Read-only
@endcannot
```

Crema checks, in order:

1. `__abilities` as a `Set` / `List` containing the ability string, or a `Map` whose value for that key is truthy
2. A `can` map in the data (`can['edit']` truthy)

## `@switch`

```crema
@switch(status)
@case(1)
  Open
  @break
@case(2)
  Closed
  @break
@default
  Unknown
@endswitch
```

Cases compare stringified values. `@break` stops the active arm; `@default` runs when no case matched.
