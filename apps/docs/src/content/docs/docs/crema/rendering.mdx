Crema evaluates expressions against the data map (and nested maps / bean getters) passed to `render`.

## Escaped echoes

`{{ expr }}` prints the value with HTML escaping (`&`, `<`, `>`, quotes):

```crema
<p>Hello {{ name }}</p>
```

Empty or missing values render as an empty string.

## Raw HTML

`{!! expr !!}` prints without escaping — use only for trusted markup:

```crema
<div>{!! html !!}</div>
```

## Literal `@`

Write `@@` when you need a literal at-sign in the output (for example documenting directives).

## `@json`

`@json($expr)` encodes a data value as JSON (Jackson). Useful for embedding structured data in scripts or attributes:

```crema
<script>
  window.user = @json($user);
</script>
```

```kotlin
engine.render("page", mapOf("user" to mapOf("name" to "Ada", "id" to 1)))
// → window.user = {"name":"Ada","id":1};
```

## `@lang`

`@lang('key')` resolves a translation string. Crema prefers a `lang` map in the view data when present; otherwise it calls `Lang.get` from `kona-support`.

```crema
@lang('messages.welcome')
@lang('messages.hello', replace)
```

The optional second argument is an expression that evaluates to a `Map` of replacements (`:name` style placeholders).

```kotlin
engine.render(
    "greet",
    mapOf(
        "replace" to mapOf("name" to "Ada"),
        // or: "lang" to mapOf("messages.hello" to "Hi :name"),
    ),
)
```

Wire a real translator by registering `SupportServiceProvider` (or calling `Lang.setTranslator`) before rendering.

## `@asset`

`@asset('css/app.css')` builds a public URL for a path under your asset root. With no base in the data map it emits `/css/app.css`. Pass `asset_url` or `assetUrl` to prefix a CDN:

```crema
<link rel="stylesheet" href="@asset('css/app.css')" />
```

See also [Forms](/docs/crema/forms#asset-urls) for the same helper in form layouts.

## `@vite`

`@vite('resources/js/app.js')` emits a script (or link) tag pointing at `/build/...`. Lists are supported:

```crema
@vite('resources/js/app.js')
@vite(['resources/js/app.js', 'resources/css/app.css'])
```

`.css` entries become `<link rel="stylesheet">`; everything else becomes `<script type="module">`. This helper is intentionally thin — it does not read a Vite manifest. For full hot-reload / manifest resolution, use the Inertia asset helpers and inject the resulting HTML into the view.

## Comments

```crema
{{-- This never appears in the output --}}
```

## Expressions

Crema supports simple expressions in echoes and directives:

- Literals: `true`, `false`, `null` / `nil`, numbers, `'strings'`
- Comparisons: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Logic: `and`, `or`, `not`, `!`
- Helpers: `isset(name)`, `empty(name)`
- Paths: `user.name` (map keys or `getName()`-style getters)
