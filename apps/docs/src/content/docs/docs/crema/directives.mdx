Quick lookup for Crema syntax. For explanations and full examples, follow the “Guide” links.

## Echoes and comments

| Syntax | Purpose | Guide |
|--------|---------|-------|
| `{{ expr }}` | Escaped output | [Rendering](/docs/crema/rendering/) |
| `{!! expr !!}` | Raw HTML output | [Rendering](/docs/crema/rendering/) |
| `@@` | Literal `@` | [Rendering](/docs/crema/rendering/) |
| `{{-- … --}}` | Comment (stripped) | [Rendering](/docs/crema/rendering/) |

## Layouts and sections

| Directive | Closer / notes | Guide |
|-----------|----------------|-------|
| `@extends('layout')` | Child declares parent layout | [Layouts](/docs/crema/layouts/) |
| `@section('name', 'text')` | Inline section | [Layouts](/docs/crema/layouts/) |
| `@section('name')` | Block section | `@endsection` or `@show` |
| `@endsection` | End block section (store raw) | [Layouts](/docs/crema/layouts/) |
| `@show` | End section and expand immediately | [Layouts](/docs/crema/layouts/) |
| `@yield('name')` | Print section | Optional default: `@yield('n', 'default')` |
| `@parent` | Insert parent section buffer | Inside a child `@section` |
| `@hasSection('name')` | Body if section defined | Closes with `@endif` |
| `@sectionMissing('name')` | Body if section missing | Closes with `@endif` |

### `loop` keys

`index`, `iteration`, `first`, `last`, `count`, `remaining`, `even`, `odd`, `depth`, `parent` — see [Loop metadata](/docs/crema/control-structures/#loop-metadata).

## Components and slots

| Syntax | Purpose | Guide |
|--------|---------|-------|
| `@component('name')…@endcomponent` | Render a view as a component | [Components](/docs/crema/components/) |
| `@slot('name')…@endslot` | Named slot inside `@component` | [Components](/docs/crema/components/) |
| `<x-name>…</x-name>` | Render `components.name` | [Components](/docs/crema/components/) |
| `<x-name />` | Empty default slot | [Components](/docs/crema/components/) |
| `<x-slot name="n">…</x-slot>` | Named slot for `<x-*>` or prefixed tags | [Components](/docs/crema/components/) |
| `<x-slot:n>…</x-slot:n>` | Colon-name form | [Components](/docs/crema/components/) |
| `<prefix:slot name="n">…` | Named slot for extension tags | [Components](/docs/crema/components/) |

Inside the component view: `{{ slot }}` (default) and `{{ name }}` for each named slot.

## Custom extensions

Apps and packages can register more syntax on `CremaEngine`:

| API | Shape |
|-----|-------|
| `directive(name) { … }` | `@name` / `@name(args)` |
| `blockDirective(name) { … }` | `@name…@endname` |
| `tag(prefix) { … }` | `<prefix:name>…` |

Brew uses these for `@brew` and `<brew:…>`. See [Brew templates](/docs/brew/templates/).
