---
title: Components
description: Reusable Crema components with slots and simple x-tags.
---

Components are views rendered with a body and optional named slots.

## Define a component

```crema
{{-- alert.crema.html --}}
<div class="alert">
  <strong>{{ title }}</strong>
  <div>{{ slot }}</div>
</div>
```

- `slot` — default (unnamed) body content
- Named slots become data keys of the same name (`title` above)

## Use a component

```crema
@component('alert')
  @slot('title')Notice@endslot
  Body text goes in the default slot.
@endcomponent
```

The component view is rendered with a child context containing the expanded slots.

## `<x-*>` tags

As a lightweight alternative, Crema resolves HTML-like tags to views under `components.`:

```crema
<x-alert>Hi</x-alert>
<x-alert />
```

Both render `components.alert`. Dotted or slashed names map to nested views (`<x-inputs.button>` → `components.inputs.button`). Missing views render as empty string.

Named attributes and class-based component objects are not part of this surface yet — use `@component` / `@slot` when you need named slots.
