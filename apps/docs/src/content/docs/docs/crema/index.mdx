---
title: Getting started with Crema
description: Render HTML views with Crema templates from Kotlin or Java.
---

**Crema** is Kona’s server-side view engine. Templates live under `resources/views` as `*.crema.html` and use `@` directives plus `{{ }}` echoes.

## Render a view

Register `CremaServiceProvider`, then resolve `CremaEngine`:

```kotlin
val html = app.resolve(CremaEngine::class.java)
    .render("home", mapOf("name" to "Ada"))
return Response.html(html)
```

```java
String html = app.resolve(CremaEngine.class)
    .render("home", Map.of("name", "Ada"));
return Response.html(html);
```

`Crema.view(engine, name, data)` builds an HTML `Response` in one call. `View.with(...)` accumulates data before `render()` / `toResponse()`.

## Minimal template

```crema
{{-- resources/views/home.crema.html --}}
<h1>Hello {{ name }}</h1>
```

## Scaffolding

```bash
./grind make:view home
./grind make:view posts.show
```

Creates `resources/views/....crema.html`.

## Config

- Default path: `{basePath}/resources/views`
- Override: `view.path` in config
- CSRF: pass `_token` in the data map for `@csrf`
