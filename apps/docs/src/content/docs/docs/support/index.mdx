The `kona-support` module ships everyday helpers used across apps and the framework.

## Collections

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val names = collect(users).pluck("name").filter { it != null }
```

`Collection` wraps a list with `map`, `flatMap`, `filter`, `reduce`, `chunk`, `sum`, `avg`, `when` / `unless`, `pluck`, `groupBy`, `sortBy`, `unique`, and more. Java: `Collection.make(...)` / `Collection.of(...)`.

## Strings

```kotlin
Str.slug("Hello World")          // hello-world
Str.of("hello_world").camel()    // helloWorld
```

## Dates

`KonaDate` is a fluent Instant wrapper: `now()`, `parse()`, `addDays()`, `toDateString()`, `isPast()`, `diffInSeconds()`.

## Arrays / maps

`Arr.get`, `Arr.set`, `Arr.has`, `Arr.only`, `Arr.except`, `Arr.wrap`, and `Arr.flatten` work with nested dotted keys (`user.name`).

## Localization

```kotlin
val t = Translator().addLines("en", mapOf("hi" to "Hello :name"))
t.get("hi", mapOf("name" to "Ada"))
Lang.setTranslator(t)
translate("hi", mapOf("name" to "Ada"))
```

</TabItem>
<TabItem label="Java">

```java
Translations.__("hi", Map.of("name", "Ada"));
```

</TabItem>
</Tabs>

Register `SupportServiceProvider` to bind a shared `Translator`. If `lang.path` is set or `{base}/lang` exists, JSON and `key=value` files are loaded automatically (`lang/en.json`, `lang/en/messages.json`, `lang/en.properties`, and so on).
