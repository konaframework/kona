A **controller** is a class that groups related HTTP actions. Instead of putting every route closure in a service provider, you point routes at controller methods. Controllers keep validation, authorization, and response shaping next to each other.

How you **register** those methods on the router (including `WebRoutes`, groups, and `resource()`) is covered in [Routing](../routing/). This page focuses on what lives *inside* the controller class.

## Wire from routes

**Recommended (IDE-friendly):** instantiate the controller in `WebRoutes.register`, then bind a lambda or method reference. The IDE can autocomplete method names, jump to the action, and flag typos at compile time.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class WebRoutes(private val app: Application) {
    fun register(router: Router) {
        val projects = ProjectController(app)
        router.get("/projects") { projects.index(it) }.name("projects.index")
    }
}
```

</TabItem>
<TabItem label="Java">

```java
public final class WebRoutes {
    private final Application app;

    public WebRoutes(Application app) { this.app = app; }

    public void register(Router router) {
        ProjectController projects = new ProjectController(app);
        router.get("/projects", projects::index).name("projects.index");
    }
}
```

</TabItem>
</Tabs>

Inline handler lambdas work the same way when you do not need a controller class. Details and more verbs live on [Routing](../routing/#call-a-controller).

Generate stubs with [`./grind make:controller Name`](../../grind/commands/#grind-makecontroller). Use `--resource` when you want REST method stubs ready for [`router.resource(...)`](../routing/#resource-routes) / [`router.apiResource(...)`](../routing/#api-resource-routes).

## Base controller

Extend `Controller` when you want the shared `validate` helpers:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class NotesController : Controller() {
    fun store(request: Request): Response {
        val data = validate(request, mapOf("title" to listOf("required", "min:3")))
        return Response.json(data, 201)
    }
}

router.post("/notes") { notes.store(it) }
```

</TabItem>
<TabItem label="Java">

```java
public class NotesController extends Controller {
    public Response store(Request request) {
        Map<String, Object> data = validate(request, Map.of("title", List.of("required", "min:3")));
        return Response.json(data, 201);
    }
}

router.post("/notes", notes::store);
```

</TabItem>
</Tabs>

`validate` throws `ValidationException` (HTTP 422) when rules fail — the same path as `request.validate(...)`.

## Form requests

A **form request** is a small object that owns validation rules (and optional authorization) for one action:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class StoreNoteRequest : FormRequest() {
    override fun rules(): Map<String, List<String>> =
        mapOf("title" to listOf("required", "min:3"))

    override fun authorize(request: Request): Boolean =
        request.header("X-Token") == "secret"
}

class NotesController : Controller() {
    fun store(request: Request): Response {
        val data = validate(request, StoreNoteRequest())
        return Response.json(data, 201)
    }
}
```

</TabItem>
<TabItem label="Java">

```java
public class StoreNoteRequest extends FormRequest {
    @Override
    public Map<String, List<String>> rules() {
        return Map.of("title", List.of("required", "min:3"));
    }

    @Override
    public boolean authorize(Request request) {
        return "secret".equals(request.header("X-Token"));
    }
}
```

</TabItem>
</Tabs>

If `authorize` returns `false`, Kona throws `HttpException` with status **403**. Otherwise the rules run through the validator.

## Invokable controllers

When a route has a single action, implement `InvokableController` and register it with [`asHandler()` / `Controllers.asHandler`](../routing/#invokable-controllers):

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val ping = InvokableController { Response.text("pong") }
router.get("/ping", ping.asHandler()).name("ping")
```

</TabItem>
<TabItem label="Java">

```java
InvokableController ping = request -> Response.text("pong");
router.get("/ping", Controllers.asHandler(ping)).name("ping");
```

</TabItem>
</Tabs>

## Resource controllers

[`Router.resource(name, controller)`](../routing/#resource-routes) wires the full REST map (including `create` / `edit`) onto a `ResourceController`. Prefer [`apiResource`](../routing/#api-resource-routes) for JSON APIs (no form routes). Extend `BaseResourceController` when you only need some actions — unimplemented ones throw `NotFoundException`:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class NotesController : BaseResourceController() {
    override fun index(request: Request): Response = Response.json(listOf<Any>())
    override fun store(request: Request): Response {
        val data = validate(request, StoreNoteRequest())
        return Response.json(data, 201)
    }
}

router.apiResource("notes", NotesController())
```

</TabItem>
<TabItem label="Java">

```java
public class NotesController extends BaseResourceController {
    @Override
    public Response index(Request request) {
        return Response.json(List.of());
    }

    @Override
    public Response store(Request request) {
        return Response.json(validate(request, new StoreNoteRequest()), 201);
    }
}

router.apiResource("notes", new NotesController());
```

</TabItem>
</Tabs>
