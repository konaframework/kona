title: Controllers
description: Organize HTTP handlers into controller classes, invokable actions, resource controllers, and form-request validation.

A **controller** is a class that groups related HTTP actions. Instead of putting every route closure in a service provider, you point routes at controller methods. Controllers keep validation, authorization, and response shaping next to each other.

## Base controller

Extend `Controller` when you want the shared `validate` helpers:

```kotlin
class NotesController : Controller() {
    fun store(request: Request): Response {
        val data = validate(request, mapOf("title" to listOf("required", "min:3")))
        return Response.json(data, 201)
    }
}

router.post("/notes") { notes.store(it) }
```

```java
public class NotesController extends Controller {
    public Response store(Request request) {
        Map<String, Object> data = validate(request, Map.of("title", List.of("required", "min:3")));
        return Response.json(data, 201);
    }
}

router.post("/notes", notes::store);
```

`validate` throws `ValidationException` (HTTP 422) when rules fail — the same path as `request.validate(...)`.

## Form requests

A **form request** is a small object that owns validation rules (and optional authorization) for one action:

```kotlin
class StoreNoteRequest : FormRequest() {
    override fun rules(): Map<String, List<String>> =
        mapOf("title" to listOf("required", "min:3"))

    override fun authorize(request: Request): Boolean =
        request.header("X-Token") == "secret"
}

class NotesController : Controller() {
    fun store(request: Request): Response {
        val data = validate(request, StoreNoteRequest())
        return Response.json(data, 201)
    }
}
```

```java
public class StoreNoteRequest extends FormRequest {
    @Override
    public Map<String, List<String>> rules() {
        return Map.of("title", List.of("required", "min:3"));
    }

    @Override
    public boolean authorize(Request request) {
        return "secret".equals(request.header("X-Token"));
    }
}
```

If `authorize` returns `false`, Kona throws `HttpException` with status **403**. Otherwise the rules run through the validator.

## Invokable controllers

When a route has a single action, implement `InvokableController` and register `asHandler()`:

```kotlin
val ping = InvokableController { Response.text("pong") }
router.get("/ping", ping.asHandler()).name("ping")
```

```java
InvokableController ping = request -> Response.text("pong");
router.get("/ping", Controllers.asHandler(ping)).name("ping");
```

## Resource controllers

`Router.resource(name, controller)` wires the conventional REST map onto a `ResourceController` (`index`, `show`, `store`, `update`, `destroy`). Extend `BaseResourceController` when you only need some of those actions — unimplemented ones throw `NotFoundException`:

```kotlin
class NotesController : BaseResourceController() {
    override fun index(request: Request): Response = Response.json(listOf<Any>())
    override fun store(request: Request): Response {
        val data = validate(request, StoreNoteRequest())
        return Response.json(data, 201)
    }
}

router.resource("notes", NotesController())
```

```java
public class NotesController extends BaseResourceController {
    @Override
    public Response index(Request request) {
        return Response.json(List.of());
    }

    @Override
    public Response store(Request request) {
        return Response.json(validate(request, new StoreNoteRequest()), 201);
    }
}

router.resource("notes", new NotesController());
```
