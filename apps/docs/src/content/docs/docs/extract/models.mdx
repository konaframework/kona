A **model** is a class that represents one database table. Each instance holds one row: its **attributes** are the row's columns, keyed by column name. Models know how to find rows, insert new ones, update changed columns, and delete themselves. This style is sometimes called *active record*: the object that holds the data also knows how to persist it.

Models read the **global** database (see [Extract overview](../)), so register `ExtractServiceProvider` or call `Database.setAsGlobal()` before using them.

## Defining a model

A model extends `Extract<T>`, passing its own class as `T`, and must have a no-argument constructor. Kotlin models usually add a companion object so that `User.find(1)` reads naturally; Java models keep a static `ExtractCompanion` field.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
import dev.kona.extract.CastType
import dev.kona.extract.Extract
import dev.kona.extract.ExtractCompanion

class User : Extract<User>() {
    override val fillable = setOf("name", "email", "admin")
    override val casts = mapOf("admin" to CastType.BOOLEAN, "settings" to CastType.JSON)

    companion object : ExtractCompanion<User>(User::class.java)
}
```

</TabItem>
<TabItem label="Java">

```java
import dev.kona.extract.CastType;
import dev.kona.extract.Extract;
import dev.kona.extract.ExtractCompanion;
import java.util.Map;
import java.util.Set;

public class User extends Extract<User> {
    public static final ExtractCompanion<User> QUERY = Extract.of(User.class);

    @Override
    public Set<String> getFillable() {
        return Set.of("name", "email", "admin");
    }

    @Override
    public Map<String, Object> getCasts() {
        return Map.of("admin", CastType.BOOLEAN, "settings", CastType.JSON);
    }
}
```

</TabItem>
</Tabs>


`./grind make:model User` writes this skeleton for you under `src/main/…/app/models/` (see [Migrations](../migrations/#grind-commands)).

### Conventions you can override

Every convention is an open property (a getter in Java) on `Extract`:

| Property | Default | Meaning |
|----------|---------|---------|
| `table` | snake-case plural of the class name (`BlogPost` → `blog_posts`, `Category` → `categories`) | Table name |
| `primaryKey` | `id` | Primary key column |
| `incrementing` | `true` | Read the generated key back after insert |
| `timestamps` | `true` | Maintain `created_at` / `updated_at` |
| `createdAtColumn` / `updatedAtColumn` | `created_at` / `updated_at` | Timestamp column names |
| `fillable` | empty | Keys `fill` may set |
| `guarded` | `*` | Keys `fill` refuses (`*` guards everything not fillable) |
| `casts` | empty | Column → `CastType` or `CastsAttributes` |
| `connectionName` | `null` (default connection) | Named connection to use |
| `perPage` | `15` | Page size for `paginate()` / `simplePaginate()` / `cursorPaginate()` |

## Reading rows

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val all: List<User> = User.all()
val ada: User? = User.find(1)
val sure: User = User.findOrFail(1)          // ModelNotFoundException when missing
val some: List<User> = User.findMany(listOf(1, 2, 3))
val admins = User.where("admin", true).orderBy("name").get()
val newest = User.query().latest().first()
```

</TabItem>
<TabItem label="Java">

```java
List<User> all = User.QUERY.all();
User ada = User.QUERY.find(1);
User sure = User.QUERY.findOrFail(1);
List<User> some = User.QUERY.findMany(List.of(1, 2, 3));
List<User> admins = User.QUERY.where("admin", true).orderBy("name").get();
User newest = User.QUERY.query().latest().first();
```

</TabItem>
</Tabs>


`query()` returns a `ModelBuilder<T>`. It accepts the same constraints as the [query builder](../query-builder/) (`where`, `whereIn`, `orderBy`, `limit`, joins, …) but returns model instances instead of maps. Call `toBase()` to get the underlying `QueryBuilder`, or `toSql()` to see the generated SQL.

### Attributes

Read attributes with `getAttribute("name")`, the Kotlin index operator `user["name"]`, or the typed `user.attribute<String>("name")`. Set them with `setAttribute` or `user["name"] = "Ada"`. Reads apply casts; `getRawAttribute` returns the stored value untouched.

A model remembers the values it was loaded with. `isDirty()` / `getDirty()` report attributes changed since then, `getOriginal()` returns the loaded values, and `toMap()` renders cast attributes plus loaded relations, ready for `Response.json(...)`.

## Writing rows

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val user = User.create(mapOf("name" to "Ada", "email" to "ada@example.com"))  // insert

user["name"] = "Ada Lovelace"
user.save()                                   // update of the changed column only

user.update(mapOf("admin" to true))           // fill + save
user.delete()

User.where("admin", false).update(mapOf("active" to false))   // mass update
User.destroy(4, 5, 6)                                          // load and delete each
```

</TabItem>
<TabItem label="Java">

```java
User user = User.QUERY.create(Map.of("name", "Ada", "email", "ada@example.com"));

user.setAttribute("name", "Ada Lovelace");
user.save();

user.update(Map.of("admin", true));
user.delete();

User.QUERY.where("admin", false).update(Map.of("active", false));
User.QUERY.destroy(4, 5, 6);
```

</TabItem>
</Tabs>


`save()` inserts a new model or updates a loaded one. On insert, it reads back the generated key into `id`. On update, it writes only dirty attributes, and does nothing when there are none. When `timestamps` is on, it sets `updated_at` on every write and `created_at` on insert, unless you set them yourself.

`fresh()` returns a newly loaded copy of the row; `refresh()` reloads the current instance in place.

### Mass assignment

`create`, `fill`, and `update` take a map of attributes. To stop a request body from setting columns you did not intend (`admin`, `id`), they only accept keys listed in `fillable`. With the default `guarded = setOf("*")` and an empty `fillable`, any key throws `MassAssignmentException`. Use `forceFill` when you deliberately want to set every key, for example from trusted code.

## Casts

A cast converts a stored column value into a convenient type on read. Declare casts in `casts` as either a built-in `CastType` or a custom `CastsAttributes` class:

| `CastType` | Read as |
|------------|---------|
| `INT`, `LONG`, `DOUBLE` | `Int`, `Long`, `Double` |
| `BOOLEAN` | `Boolean` (accepts `1`/`0`, `"true"`/`"false"`) |
| `STRING` | `String` |
| `JSON` | `Map` or `List` from JSON text; maps and lists are written back as JSON |
| `DATETIME` | `java.time.LocalDateTime` |
| `INSTANT` | `java.time.Instant` |

Timestamp columns (and `deleted_at` on soft-deleting models) are cast to `Instant` automatically.

### Custom casts

Implement `CastsAttributes` when you need domain types (money in cents, value objects, encrypted blobs):

```kotlin
class CentsCast : CastsAttributes {
    override fun get(model: Extract<*>, key: String, value: Any?, attributes: Map<String, Any?>): Any? {
        if (value == null) return null
        val cents = (value as Number).toLong()
        return cents / 100.0
    }

    override fun set(model: Extract<*>, key: String, value: Any?, attributes: Map<String, Any?>): Any? {
        if (value == null) return null
        return Math.round((value as Number).toDouble() * 100)
    }
}

class Product : Extract<Product>() {
    override val casts = mapOf("price" to CentsCast())
}
```

Java overrides return `Map<String, Object>` from `getCasts()` so both enums and cast instances fit.

## Soft deletes

A **soft delete** marks a row as deleted by setting a `deleted_at` timestamp instead of removing it, so it can be restored. Implement the `SoftDeletes` interface:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
import dev.kona.extract.SoftDeletes

class Post : Extract<Post>(), SoftDeletes {
    companion object : ExtractCompanion<Post>(Post::class.java)
}

post.delete()                    // sets deleted_at
post.trashed()                   // true
Post.all()                       // excludes trashed rows
Post.withTrashed().get()         // includes them
Post.onlyTrashed().get()         // only them
post.restore()                   // clears deleted_at
post.forceDelete()               // removes the row
```

</TabItem>
<TabItem label="Java">

```java
import dev.kona.extract.SoftDeletes;

public class Post extends Extract<Post> implements SoftDeletes {
    public static final ExtractCompanion<Post> QUERY = Extract.of(Post.class);
}

post.delete();
post.trashed();
Post.QUERY.all();
Post.QUERY.withTrashed().get();
Post.QUERY.onlyTrashed().get();
post.restore();
post.forceDelete();
```

</TabItem>
</Tabs>


Override `deletedAtColumn` to use another column name. Add the column in a migration with `softDeletes()`.

## Pagination

`paginate(perPage, page)` runs a count query plus one page query and returns a `Page<T>`:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val page = User.query().orderBy("name").paginate(20, request.query["page"]?.toIntOrNull() ?: 1)
page.data          // List<User> for this page
page.total         // total rows
page.lastPage      // last page number (at least 1)
page.hasMorePages()
Response.json(page.toMap())   // {"data":[…],"total":…,"per_page":20,"current_page":…,"last_page":…}
```

</TabItem>
<TabItem label="Java">

```java
Page<User> page = User.QUERY.query().orderBy("name").paginate(20, 1);
page.getData();
page.getTotal();
page.getLastPage();
page.hasMorePages();
Response.json(page.toMap());
```

</TabItem>
</Tabs>


Page numbers start at 1; values below 1 are treated as page 1.

### Simple and cursor pagination

When you do not need a total count, `simplePaginate` fetches `perPage + 1` rows and exposes `hasMorePages()`:

```kotlin
val page = User.query().orderBy("id").simplePaginate(20, 1)
page.hasMorePages()
page.toMap()   // data, per_page, current_page, has_more
```

`cursorPaginate` walks an ordered column with opaque cursors (no offset drift on inserts):

```kotlin
val first = User.cursorPaginate(20)
val next = User.cursorPaginate(20, first.nextCursor)
// CursorPage: data, per_page, next_cursor, prev_cursor
```

## Dirty tracking after save

`isDirty` / `getDirty` describe changes since the last load. After a successful `save()`, use `wasChanged` / `getChanges` for what that save persisted:

```kotlin
user["name"] = "Ada"
user.save()
user.wasChanged("name")   // true
user.getChanges()         // map of persisted attributes
user.save()               // no-op when clean → wasChanged() is false
```

## Retrieving or creating

When you want “find this row, or make one” in a single call:

| Call | Behavior |
|------|----------|
| `firstOrNew(attributes)` | Returns the first match, or a new **unsaved** model filled with `attributes` |
| `firstOrCreate(attributes, values)` | Returns the first match, or **creates** a row from `attributes` merged with optional `values` |
| `updateOrCreate(attributes, values)` | Updates the first match with `values`, or creates `attributes + values` |

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val user = User.firstOrCreate(
    mapOf("email" to "ada@example.com"),
    mapOf("name" to "Ada"),
)
val flight = Flight.updateOrCreate(
    mapOf("departure" to "OAK", "destination" to "SDY"),
    mapOf("price" to 99, "discounted" to true),
)
```

</TabItem>
<TabItem label="Java">

```java
User user = User.QUERY.firstOrCreate(
    Map.of("email", "ada@example.com"),
    Map.of("name", "Ada")
);
Flight flight = Flight.QUERY.updateOrCreate(
    Map.of("departure", "OAK", "destination", "SDY"),
    Map.of("price", 99, "discounted", true)
);
```

</TabItem>
</Tabs>


`wasRecentlyCreated()` is true only when the last `save()` inserted that instance (useful after `firstOrCreate`).

## Upserts and insert-or-ignore

On the model query (or the table [query builder](../query-builder/#upserts)):

```kotlin
User.query().upsert(
    listOf(
        mapOf("email" to "a@example.com", "name" to "A"),
        mapOf("email" to "b@example.com", "name" to "B"),
    ),
    uniqueBy = listOf("email"),
    update = listOf("name"),
)

User.query().updateOrInsert(
    mapOf("email" to "ada@example.com"),
    mapOf("name" to "Ada Lovelace"),
)

User.query().insertOrIgnore(
    listOf(mapOf("email" to "ada@example.com", "name" to "Ada")),
    uniqueBy = listOf("email"),
)
```

`upsert` walks each row: when a row matching `uniqueBy` exists it updates the listed columns (or every non-unique column when `update` is omitted); otherwise it inserts. Prefer a unique index on those columns in the schema so concurrent writers do not race.

## Query scopes

Reusable filters are ordinary methods on your companion (or static helpers in Java) that return a `ModelBuilder`:

```kotlin
class User : Extract<User>() {
    companion object : ExtractCompanion<User>(User::class.java) {
        fun admins(): ModelBuilder<User> = query().where("admin", true)
        fun named(name: String): ModelBuilder<User> = query().where("name", name)
    }
}

User.admins().orderBy("name").get()
```

Inline scopes use `scope { … }` or conditional `when` / `unless`:

```kotlin
User.query()
    .scope { it.where("active", true) }
    .when(onlyAdmins) { it.where("admin", true) }
    .unless(includeBanned) { it.where("banned", false) }
    .get()
```

## Accessors and mutators

Override `getMutatedAttribute` (after casts on read) and `setMutatedAttribute` (before casts on write) to transform values:

```kotlin
class User : Extract<User>() {
    override fun getMutatedAttribute(key: String, value: Any?): Any? =
        if (key == "name" && value is String) value.uppercase() else value

    override fun setMutatedAttribute(key: String, value: Any?): Any? =
        if (key == "email" && value is String) value.lowercase() else value
}
```

Virtual fields for serialization still use `appends` + `getAppendedAttribute` — see [Serialization & events](../serialization-events/).

## Replicating, touching, and comparing

```kotlin
val copy = user.replicate()                    // unsaved clone without id / timestamps
val draft = user.replicate(setOf("email"))     // also skip email
user.touch()                                   // bump updated_at and persist
user.`is`(other)                               // same class + same non-null primary key
user.isNot(other)
```

## Chunking large result sets

```kotlin
User.query().orderBy("id").chunk(200) { batch ->
    batch.forEach { process(it) }
}
```

Each chunk runs a page query (`forPage`). Always `orderBy` a stable column so pages do not skip or repeat rows under concurrent writes.

## Quiet persistence

`saveQuietly()` and `deleteQuietly()` persist without firing [model events](../serialization-events/#lifecycle-events). For a whole block of work, use `ModelDispatcher.withoutEvents { … }`.
