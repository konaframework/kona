IntelliJ IDEA uses a **native** JetBrains plugin — [kona-idea](https://github.com/konaframework/kona-idea) — the same approach as other first-class JetBrains language plugins. Crema is a real file type with an HTML-layered highlighter, not a TextMate bundle.

| | |
| --- | --- |
| Repository | [konaframework/kona-idea](https://github.com/konaframework/kona-idea) |
| Plugin id | `dev.kona.idea` |
| Releases | [GitHub Releases](https://github.com/konaframework/kona-idea/releases) (`.zip`) |
| Products | IntelliJ IDEA Community and Ultimate (2024.2+) |

Installing, updating, or removing the plugin requires an IDE restart.

## Install

1. Download the latest `kona-idea-*.zip` from [Releases](https://github.com/konaframework/kona-idea/releases) (current line: **v0.1.0**).
2. **Settings → Plugins → ⚙ → Install Plugin from Disk…** and choose the zip.
3. Restart when prompted.
4. Open a Crema view (`resources/views/….crema.html` or `*.crema.kt`). Confirm the language chip shows **Crema** (not HTML).

## What you get

- Native Crema lexer: HTML colors plus `@directives`, `{{ }}`, `{!! !!}`, `{{-- --}}`
- Directive completion (Ctrl+Space on `@…`)
- Warnings for unknown `@name` tokens (emails like `hi@example.com` are ignored)
- `{{` auto-closes as `{{  }}` with the caret in the middle
- **Grind** run configuration type for `./grind …`
- **Kona** menu → **Show kona-lsp Setup Help** (optional language server; not started by default)

## Develop the plugin

```bash
git clone https://github.com/konaframework/kona-idea.git
cd kona-idea
./gradlew test
./gradlew buildPlugin   # → build/distributions/*.zip
./gradlew runIde        # sandboxed IntelliJ with the plugin loaded
```

Keep `CremaDirectives` in the plugin in sync with `modules/lsp` `CremaDirectives` in this repository when you add template directives. Agent resume notes for the plugin live in that repo’s [`HANDOFF.md`](https://github.com/konaframework/kona-idea/blob/main/HANDOFF.md).

## Optional: TextMate or LSP only

If you cannot install the zip, see the legacy TextMate notes in `ide-support/intellij/README.md`. For a stdio language server used by other tooling:

```bash
./gradlew :kona-lsp:jar
java -jar modules/lsp/build/libs/kona-lsp-*.jar
```

Details: [Language server](/docs/language/lsp).
