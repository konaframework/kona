---
title: Concurrency
description: Virtual-thread helpers for parallel map and task lists.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

**Concurrency** helpers run work on JDK virtual threads so you can fan out CPU-light or IO-bound work without managing a thread pool by hand.

## Parallel map

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val doubled = Concurrency.map(listOf(1, 2, 3)) { it * 2 }
```

</TabItem>
<TabItem label="Java">

```java
List<Integer> doubled = Concurrency.map(List.of(1, 2, 3), n -> n * 2);
```

</TabItem>
</Tabs>

Empty input returns an empty list without starting an executor.

## Task list

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val results = Concurrency.run(
    listOf(
        Callable { fetchA() },
        Callable { fetchB() },
    )
)
```

</TabItem>
<TabItem label="Java">

```java
List<String> results = Concurrency.run(List.of(
    (Callable<String>) () -> fetchA(),
    (Callable<String>) () -> fetchB()
));
```

</TabItem>
</Tabs>

Results preserve input order. Exceptions from a task propagate when the future is collected.
