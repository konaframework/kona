Patterns that combine Wire’s bundled Alpine with server components.

## Dropdown + server action

```html
<div x-data="{ open: false }">
  <button type="button" @click="open = ! open">Account</button>
  <div x-show="open" @click.outside="open = false" x-cloak>
    <button type="button" wire:click="logout">Log out</button>
  </div>
</div>
```

## Call the server from Alpine

```html
<div x-data>
  <button
    type="button"
    @click="
      const n = await $wire.doubled();
      alert(n);
    "
  >Double count</button>
</div>
```

```kotlin
fun doubled(): Int = count * 2
```

## Entangle a field

```html
<div x-data="{ local: @entangle('query').live }">
  <input x-model="local" placeholder="Search…" />
  <p x-text="'Local: ' + local"></p>
</div>
```

## Listen for Wire events in Alpine

```kotlin
fun save() {
    dispatch("post-saved", mapOf("id" to id))
}
```

```html
<div
  x-data
  x-on:post-saved.window="console.log($event.detail)"
>
  <button type="button" wire:click="save">Save</button>
</div>
```

## Custom control with `x-modelable`

```html
<div x-data="{ value: '' }" x-modelable="value" wire:model="title">
  <input x-model="value" />
</div>
```

Wire’s `wire:model` binds through Alpine’s modelable surface — see [Forms](/docs/wire/essentials/forms/).

## Register a hook before start

```html
<script>
  document.addEventListener('brew:init', () => {
    Wire.hook('commit', ({ component }) => {
      console.debug('commit', component.name)
    })
  })
</script>
@wireScripts
```
