## 1. Scaffold or hand-write

```bash
./grind make:wire counter
# or: ./grind make:wire counter --lang=java
# single-file instead: ./grind make:wire counter --inline
```

By default that creates an empty `Counter` class and `views/wire/counter.crema.html` with a short quote in a `<p>` tag. Replace the view (and add state/actions on the class) as you build — or hand-write the counter below.

Put classes in `app.wire` (or configure `wire.class_namespace`).

## 2. Component class

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
package app.wire

import org.konaframework.wire.Component

class Counter : Component() {
    var count = 0

    fun mount(start: Int = 0) {
        count = start
    }

    fun increment() {
        count++
    }

    fun decrement() {
        count--
    }

    override fun template() = """
        <div>
            <button type="button" wire:click="decrement">−</button>
            <span>{{ count }}</span>
            <button type="button" wire:click="increment">+</button>
        </div>
    """.trimIndent()
}
```

</TabItem>
<TabItem label="Java">

```java
package app.wire;

import org.konaframework.wire.Component;

public class Counter extends Component {
    public int count = 0;

    public void mount(int start) {
        count = start;
    }

    public void increment() {
        count++;
    }

    public void decrement() {
        count--;
    }

    @Override
    public String template() {
        return """
            <div>
                <button type="button" wire:click="decrement">−</button>
                <span>{{ count }}</span>
                <button type="button" wire:click="increment">+</button>
            </div>
            """;
    }
}
```

## 3. Embed in a page

Attributes become mount parameters / initial props (`:start="3"` → `mount(start = 3)`).

```crema
{{-- views/welcome.crema.html --}}
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Welcome</title>
    @wireStyles
</head>
<body>
    <h1>Welcome</h1>
    <wire:counter :start="3" />
    {{-- or: @wire('counter', ['start' => 3]) --}}
    @wireScripts
</body>
</html>
```

You can also mount from code:

```kotlin
val html = Wire.mount("counter", mapOf("start" to 3))
```

## 4. Route to the page

Wire a normal Kona route that returns the Crema view (see [Kona routing](/docs/http/routing/)). On first paint you should see `3`. Each click posts to `/wire/update` and morphs the new HTML.

## 5. Test without a browser

```kotlin
Wire.test(Counter::class.java)
    .set("count", 1)
    .call("increment")
    .assertSet("count", 2)
    .assertSee("2")
```

```java
Wire.test(Counter.class)
    .set("count", 1)
    .call("increment")
    .assertSet("count", 2)
    .assertSee("2");
```

## What you just used

| Piece | Role |
|-------|------|
| Public `count` | Snapshot state |
| `increment` / `decrement` | Browser-callable actions |
| `wire:click` | Alpine-backed event → server call |
| `{{ count }}` | Crema interpolation on re-render |
| Single root `<div>` | Required for morph |
