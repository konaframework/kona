**Kona Wire** (short name **Wire**) is Kona’s reactive server-component layer. You write Kotlin or Java classes with public state and actions, render HTML with [Crema](/docs/crema/), and Wire keeps the browser in sync over a small JSON protocol—without a full page reload.

Wire ships as `org.konaframework:kona-wire` on [Maven Central](https://repo1.maven.org/maven2/org/konaframework/kona-wire/). Scaffold with `kona new my-app --kit=wire`, or add the dependency with `./grind install wire` (or `kona grind install wire`). The previous product name **Brew** remains as a compatibility alias for the 0.3.0 train (`--kit=brew`, `./grind install brew`, `<brew:name />`, and the deprecated `kona-brew` artifact).
