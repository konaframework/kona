Kona is a web framework for the JVM. You boot an **application**, plug features in with **service providers**, look services up from a **container**, and answer HTTP requests with **routes** and **middleware**. The same APIs work from Kotlin and Java, and the **grind** command-line tool scaffolds and serves your project.
