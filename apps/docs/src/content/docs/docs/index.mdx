This is the documentation hub for **Kona**. The marketing home lives at the site root; everything below is how to build with the framework.

Kona boots an **application**, plugs features in with **service providers**, looks services up from a **container**, and answers HTTP with **routes** and **middleware**. The same APIs work from Kotlin and Java. The **grind** CLI scaffolds and serves your project.
