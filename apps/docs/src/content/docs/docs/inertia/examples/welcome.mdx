---
title: Welcome page
description: Minimal route that renders Pages/Welcome with a message prop.
---

```kotlin
router.get("/") {
    Inertia.render(
        "Pages/Welcome",
        mapOf("message" to "Welcome to Kona Inertia"),
    )
}
```

```java
router.get("/", request ->
    Inertia.render("Pages/Welcome", Map.of("message", "Welcome to Kona Inertia"))
);
```

First visit → HTML `data-page` containing the component name. Inertia visit → JSON with the same props.
