## Runtime

| Requirement | Notes |
|-------------|--------|
| **JDK 21+** | Virtual threads; same as Kona core |
| **Kona modules** | `kona-http`, and usually `kona-crema` for the root view — from Maven Central (current line: **0.1.1**) |
| **Inertia** | `org.konaframework:kona-inertia` on Maven Central |

## Frontend (your app)

Inertia itself does not bundle Vue/React/Svelte. Your app’s `package.json` should add an Inertia adapter (for example `@inertiajs/vue3`) and Vite. The **inertia** starter kit drops a Vite app whose entry is `src/main/resources/js/app.js` (Vue and Svelte) or `app.jsx` (React). Pass `--typescript` for `app.ts` / `app.tsx` plus `tsconfig.json`. The web root those builds emit into is project-root `public/build`.

## Docs site

Building this documentation under `apps/docs/` needs **Node 22+**.
