**Inertia** for Kona lets your JVM app return a **page object** — component name plus props — that a JavaScript client hydrates. The first visit is a normal HTML document; later navigations send the `X-Inertia` header and receive JSON.

Inertia ships as a separate artifact (`dev.kona:kona-inertia`) from the [kona-inertia](https://github.com/konaframework/kona-inertia) repository. Scaffold with `kona new my-app --kit=inertia`, or add the dependency (and provider) with `kona install inertia`.

**[Inertia documentation →](https://konaframework.github.io/kona-inertia/)**

Full guides live on that site: rendering, shared data, middleware, versioning, Vite, testing, and Kotlin/Java samples.
