title: 租户、插件与导入
description: "指向租户、插件，以及导入和导出。"
---

三个主题位于面板旁边，各自有自己的页面。打开你需要的那一页。

- [租户](/docs/firefly/tenancy/) 是租户菜单和 `Resource.tenant`。
- [插件](/docs/firefly/plugins/) 是 `FireflyPlugin.register` 和 `boot`。
- [导入和导出](/docs/firefly/import-export/) 是 CSV 任务，以及用于已渲染页面的 `Firefly.test`。

`kona new desk --kit=firefly` 是安装路径。它写在[安装](/docs/firefly/installation/)。它不是单独的运行时。
