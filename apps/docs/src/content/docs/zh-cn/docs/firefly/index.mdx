**Kona Firefly**（简称 **Firefly**）是 Kona 给运行应用的人用的面板。**面板**是站点上一个已登录（或公开）的区域：一个品牌、一棵导航树，以及列出和编辑记录的屏幕。Firefly 在服务器上绘制这个区域。按钮、对话框和实时字段通过 [Wire](/docs/wire/) 和 Alpine 留在浏览器里。

当工作是“打开工作台、找到订单、改它，并看到它已保存”时使用 Firefly — 当工作是公开营销页或 JSON API 时不用它。那些留在普通的 Kona 路由上。加入 Firefly 模块不会改写你已经定义的路由。路由在 `Panel` 调用 `mount` 时出现。

## 你构建什么

面板是 `app/firefly` 里一个名为 `Panel` 的类。它发现自己旁边的三个文件夹：

| 文件夹 | 放什么 |
|--------|--------|
| `pages/` | 你自己设计的屏幕，例如工作台 |
| `widgets/` | 放在页面上的统计、图表和其他卡片 |
| `resources/` | 每种记录类型一个类，例如笔记或订单 |

hello 示例（`samples/hello-kotlin` 和 `samples/hello-java`）就是这个布局，挂在 `/admin`。这些指南跟随的就是同一批示例。

## 其余部分怎么读

第一次按侧栏从上到下：

1. [要求](/docs/firefly/requirements/) — JDK 和你已经有的 Kona 应用。
2. [安装](/docs/firefly/installation/) — `kona new --kit=firefly`，或把模块加到现有应用。
3. [登记面板](/docs/firefly/registration/) — `Panel` 文件、文件夹和 `discover`。
4. [一个能工作的应用](/docs/firefly/working-app/) — 一个简单的笔记资源和一个完整的订单资源。

之后，每个组件有自己的页面：它是什么、请求如何使用它、存在哪些方法，以及 Kotlin 和 Java 示例。准备离开演练时，从[面板](/docs/firefly/panel/)开始。

Kotlin 和 Java 调用相同的类型。每一个重要示例都用两种语言展示。你扩展的类是 `Panel`。包是 `org.konaframework.firefly`。
