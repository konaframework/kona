租户是顶栏里的一个标签，以及为当前请求存储的一个 id。面板不会创建数据库。你的资源决定这个 id 过滤哪一列。

## 请求如何使用它

`tenant(Tenant("acme").label("Acme"))` 加上一条链接。链接设置 `?tenant=acme`。该请求渲染期间，`FireflyTenant.id()` 是 `acme`。调用了 `tenant("tenant_id")` 的资源会在 id 已设置时把该列加进 `query()`。Cadence 模型仍然返回 `ModelBuilder`。未知的租户 id 会在页面上失败，并指出这个 id。

空白的租户 id 或空白标签会抛出 `FireflyException`。空白列名会抛出 `Tenant column is blank`。

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
Panel().path("admin").tenant(Tenant("acme").label("Acme"))
Resource("orders").model(Order::class.java).tenant("tenant_id")
```

</TabItem>
<TabItem label="Java">

```java
new Panel().path("admin").tenant(new Tenant("acme").label("Acme"));
new Resource("orders").model(Order.class).tenant("tenant_id");
```

</TabItem>
</Tabs>

`label` 接受字符串或接收 `Get` 的闭包。`FireflyTenant.use(id) { ... }` 为当前线程设置 id，并在块返回时恢复先前的值。`mount` 已经在页面响应周围这样做。在测试里自己调用 `use`。

查询字符串没有 `tenant` 参数时，`FireflyTenant.id()` 为 null。

## 方法

| 类型 | 方法 |
|------|------|
| `Tenant` | `label(value)`、`label(provider)`、`label()` |
| `Panel` | `tenant(tenant)` |
| `Resource` | `tenant(column)` |
| `FireflyTenant` | `id()`、`use(id, supplier)` |
