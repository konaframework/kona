仪表盘父组件承载一个响应式面板子组件，并监听子组件事件。

## 子组件

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
class Panel : Component() {
    @field:Reactive
    var title = ""

    @field:Modelable
    var note = ""

    fun save() {
        dispatch("panel-saved", mapOf("title" to title))
    }

    override fun template() = """
        <section>
            <h2>{{ title }}</h2>
            <input wire:model.live="note" />
            <button type="button" wire:click="save">Save panel</button>
        </section>
    """.trimIndent()
}
```

</TabItem>
<TabItem label="Java">

```java
public class Panel extends Component {
    @Reactive public String title = "";
    @Modelable public String note = "";

    public void save() {
        dispatch("panel-saved", Map.of("title", title));
    }

    @Override
    public String template() {
        return """
            <section>
                <h2>{{ title }}</h2>
                <input wire:model.live="note" />
                <button type="button" wire:click="save">Save panel</button>
            </section>
            """;
    }
}
```

## 父组件

```kotlin
class Dashboard : Component() {
    var heading = "Ops"
    var draft = ""
    var lastSaved = ""

    fun onPanelSaved(title: String = "") {
        lastSaved = title
    }

    override fun template() = """
        <div>
            <p>Last saved: {{ lastSaved }}</p>
            <wire:panel
                wire:key="main"
                :title="heading"
                wire:model="draft"
                @panel-saved="onPanelSaved"
            />
        </div>
    """.trimIndent()
}
```

## 惰性子组件

class HeavyChart : Component() {
