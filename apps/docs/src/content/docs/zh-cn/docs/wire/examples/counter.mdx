import { Tabs, TabItem } from '@astrojs/starlight/components';

一个最小的交互部件：一个整数属性、两个动作、一份模板。

## 组件

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
package app.wire

import org.konaframework.wire.Component

class Counter : Component() {
    var count = 0

    fun mount(start: Int = 0) {
        count = start
    }

    fun increment() { count++ }
    fun decrement() { count-- }
    fun reset() { count = 0 }

    override fun template() = """
        <div class="counter">
            <button type="button" wire:click="decrement" wire:loading.attr="disabled">−</button>
            <span wire:text="count"></span>
            <button type="button" wire:click="increment" wire:loading.attr="disabled">+</button>
            <button type="button" wire:click="reset">Reset</button>
            <span wire:loading wire:target="increment,decrement">…</span>
        </div>
    """.trimIndent()
}
```

</TabItem>
<TabItem label="Java">

```java
package app.wire;

import org.konaframework.wire.Component;

public class Counter extends Component {
    public int count = 0;

    public void mount(int start) { count = start; }
    public void increment() { count++; }
    public void decrement() { count--; }
    public void reset() { count = 0; }

    @Override
    public String template() {
        return """
            <div class="counter">
                <button type="button" wire:click="decrement" wire:loading.attr="disabled">−</button>
                <span wire:text="count"></span>
                <button type="button" wire:click="increment" wire:loading.attr="disabled">+</button>
                <button type="button" wire:click="reset">Reset</button>
            </div>
            """;
    }
}
```

</TabItem>
</Tabs>

## 页面

```crema
<wire:counter :start="3" />
```

## 测试

```kotlin
Wire.test(Counter::class.java, mapOf("start" to 3))
    .assertSet("count", 3)
    .call("increment")
    .assertSet("count", 4)
    .call("reset")
    .assertSet("count", 0)
```

仓库示例（`samples/wire-kotlin`、`samples/wire-java`）在欢迎页上提供了类似的计数器。
