**Kona Wire**（简称 **Wire**）是 Kona 的响应式服务器组件层。你用 Kotlin 或 Java 编写带有公开状态和动作的类，用 [Crema](/docs/crema/) 渲染 HTML，Wire 通过一套小型 JSON 协议让浏览器保持同步，而不必整页重新加载。

Wire 以 `org.konaframework:kona-wire` 发布在 [Maven Central](https://repo1.maven.org/maven2/org/konaframework/kona-wire/)。用 `kona new my-app --kit=wire` 搭建，或用 `./grind install wire`（或 `kona grind install wire`）加入依赖。先前的产品名 **Brew** 在 0.3.0 系列中仍作为兼容别名（`--kit=brew`、`./grind install brew`、`<brew:name />`，以及已弃用的 `kona-brew` 构件）。
