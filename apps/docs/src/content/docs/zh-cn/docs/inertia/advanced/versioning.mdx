---
title: Asset versioning
description: X-Inertia-Version negotiation and 409 conflict responses.
---

Set a version string so clients hard-reload when assets change:

```kotlin
Inertia.version("1")
// or config inertia.version / middleware version(request)
```

`versionConflict(request)` returns a `409` when **all** of:

1. The request is Inertia (`X-Inertia` present)
2. The client sent `X-Inertia-Version`
3. The manager version is non-empty and differs from the client

The response carries `X-Inertia-Location` set to the request URL (path + query) so the adapter performs a full `window.location` visit. Middleware then `decorate`s so `X-Inertia-Version` matches the server. The body is empty and there is no `X-Inertia: true` header on the conflict response (protocol control response).
