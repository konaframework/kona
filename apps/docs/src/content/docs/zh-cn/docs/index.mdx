这是 **Kona** 的文档中心。营销首页在站点根路径；下面的内容是如何用这个框架来构建。

Kona 启动一个**应用**，用**服务提供者**接入功能，从**容器**查找服务，并用**路由**和**中间件**响应 HTTP。同一套 API 可以从 Kotlin 和 Java 调用。**grind** CLI 负责搭建和运行你的项目。

刚接触时按侧栏顺序阅读：**入门** → **基础** → **Crema**，然后是**深入**，再按需要进入**安全**、**数据库**、**前端**、**测试**和**包与工具**。
