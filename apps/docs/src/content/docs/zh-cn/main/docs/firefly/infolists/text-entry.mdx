`TextEntry` is the default way to show a string, number, date, or list on a view page. It inherits every helper on [Entry](/docs/firefly/infolists/#helpers-on-every-entry) (`label`, `state`, `placeholder`, `url`, `copyable`, and the rest). Reach for it first; switch to icon, image, color, or code only when those shapes fit better.

## Make a text entry

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
TextEntry.make("title")
    .label("Title")
    .state("A short title")
    .size("lg")
    .weight("bold")
    .fontFamily("sans")
    .prose(true)
    .lineClamp(3)
    .limit(80)
    .words(12)
```

</TabItem>
<TabItem label="Java">

```java
TextEntry.make("title")
    .label("Title")
    .state("A short title")
    .size("lg")
    .weight("bold")
    .fontFamily("sans")
    .prose(true)
    .lineClamp(3)
    .limit(80)
    .words(12);
```

</TabItem>
</Tabs>

Nested attributes use a dotted path (up to four levels): `TextEntry.make("project.name").label("Project")` reads `project.name` from filled state, a nested map, or the schema’s Cadence record. On a resource view (or manage View dialog), Firefly loads that relation onto the record and refills state so the entry is not blank.

## Typography options

| Method | Effect |
|--------|--------|
| `size` | `xs`, `sm`, `md`, `lg`, `xl` (aliases `small` → `sm`, `medium`/`base` → `md`, `large` → `lg`) |
| `weight` | `thin`, `light`, `normal`, `medium`, `semibold`, `bold`, `extrabold` |
| `fontFamily` | `sans`, `serif`, `mono` |
| `prose(true)` | Prose styling flag on the text host |
| `lineClamp(n)` | Clamp to `n` lines |
| `limit(chars)` | Truncate plain text to that many characters |
| `words(count)` | Truncate to that many words |

## Badges and lists

`badge(true)` paints each item as a chip. Collections can render as bullets (`bulleted(true)`), line breaks (`listWithLineBreaks(true)`), or a comma-separated string when neither is set.

`limitList(n)` caps how many items show. With `expandableLimitedList(true)`, the extra items stay in the DOM marked `data-ff-extra`. Without that flag, the tail becomes `+N`.

| Method | Effect |
|--------|--------|
| `badge` / `badge(true)` | Chip per item |
| `bulleted(true)` | `<ul class="ff-bullets">` |
| `listWithLineBreaks(true)` | One `.ff-text-item` per value |
| `limitList(n)` | Cap visible items |
| `expandableLimitedList(true)` | Keep extras in the DOM as `data-ff-extra` |

## Markdown and HTML

`markdown(true)` renders a small Markdown subset (emphasis, code, links, and fenced blocks). **`html()`** (or `html(true)`) leaves the string as trusted HTML instead of escaping it — use only for content you control.

## Dates, money, and numbers

| Method | Effect |
|--------|--------|
| `date()` / `date(pattern)` | Human date (`MMMM d, yyyy`) or custom pattern |
| `dateTime()` / `dateTime(pattern)` | Date + time (`MMMM d, yyyy, h:mm a`) |
| `time()` / `time(pattern)` | Time (`HH:mm` by default) |
| `since()` | Relative phrase against the current instant |
| `timezone(zone)` | Zone id for temporal formatting |
| `dateTooltip()` / `dateTooltip(pattern)` | `data-ff-date-tooltip` (default `yyyy-MM-dd`) |
| `money` / `currency` | Currency style via `NumberFormat` |
| `numeric()` / `numeric(decimals)` | Number formatting |
| `formatStateUsing` | Replace the formatted text with the closure’s string |

Instant, `LocalDateTime`, JDBC timestamps, epoch millis, and SQL-style strings (`2024-06-15 08:30:00`) all humanize. Entries named like `due_on` or `created_at` humanize even without `.date()` / `.dateTime()`.

`money()` / `currency("USD")` formats with currency style. `money("EUR")` or `currency("KES", "en-KE", 0)` selects the code, locale, and precision.

TextEntry.make("price").money("USD")
TextEntry.make("score").numeric(1)
TextEntry.make("label").formatStateUsing { get -> get.get("label").toString().uppercase() }
```

</TabItem>

```

## Relationship aggregates

Show a number computed from related rows on the infolist record. `counts` needs the relationship name. `avg`, `min`, `max`, and `sum` also need the column on those rows.

The record is a Cadence model or a map. On a saved model, Kona loads the aggregate from the database when that relationship is not already on the record. On a map, put the related rows under the relationship key: a list of maps, one map, or one model. A count or sum with no rows is `0`. An average, minimum, or maximum with no numeric values is empty, and the placeholder is what you see. Non-numeric column values are skipped by `avg`, `min`, `max`, and `sum`. They still count as rows for `counts`. Names are trimmed. A blank relationship or column throws `FireflyException`.

When the related rows are not on the record, a stored `books_count`, `books_avg_votes`, `books_min_votes`, `books_max_votes`, or `books_sum_votes` is shown as-is. The entry name can match that stored key or be any other name; the relationship arguments choose the rows. `state(...)` still replaces the computed number when you set it. Call `numeric(decimals)` when you want a fixed number of decimal places.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
TextEntry.make("books_count").counts("books")
TextEntry.make("books_avg_votes").avg("books", "votes").numeric(1)
TextEntry.make("books_min_votes").min("books", "votes")
TextEntry.make("books_max_votes").max("books", "votes")
TextEntry.make("books_sum_votes").sum("books", "votes")
```

## Defaults for every make

`TextEntry.configureUsing { entry -> entry.size("sm") }` runs for every later `make()`. Pass `null` to clear it.
