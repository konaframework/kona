**搜索**为应用记录建立索引，并对可替换的引擎做全文式查询。

## 注册

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.register(SearchServiceProvider())
```

| 键 | 含义 |
|----|------|
| `search.default` | 引擎名（默认 `collection`） |
| `search.engines.{name}.driver` | `collection`、`array` 或 `memory` |

## 可搜索类型

```kotlin
data class Post(val id: String, val title: String) : Searchable {
    override fun searchableAs() = "posts"
    override fun getScoutKey() = id
    override fun toSearchableArray() = mapOf("title" to title)
}
```

## 索引与查询

```kotlin
Scout.update(post)
val result = Scout.search("posts", "kona")
result.keys() // matching scout keys
Scout.remove(post)
```

</TabItem>
<TabItem label="Java">

```java
Scout.update(article);
SearchResult result = Scout.search("articles", "kona");
```

</TabItem>
</Tabs>

## 集合引擎

内置的 **collection** 引擎把文档放在内存里，当查询出现在任一已索引字段中时即匹配（不区分大小写）。它是本地开发和测试用的具体驱动；其他引擎可以实现 `Engine`。
