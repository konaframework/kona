**Crema** 是 Kona 的服务端视图引擎。你在 `src/main/resources/views` 下写模板，从控制器传入数据映射，Crema 把 `@` 指令和 `{{ }}` 回显展开成 HTML。模板使用扩展名 `*.crema.html` 或 `*.crema.kt`（同样指令语法的纯文本）。

Crema 受到常见服务端模板菜单的启发；这句话之后的一切都按 Crema 自身的术语来描述。

## 视图是什么

**视图**是一份具名模板加上用来渲染它的数据。名称用点分隔（`home`、`posts.show`），并映射到视图根下的文件路径（`home.crema.html`、`posts/show.crema.html`）。启动之后，[视图辅助方法](/docs/crema/view-helper/)通过绑定到应用的引擎解析该名称，并返回一个 `View`（或 HTML `Response`）。

典型请求路径：

1. 一条路由命中控制器方法。
2. 控制器调用 `view("welcome", …)`（Kotlin）或 `Views.make("welcome", …)`（Java）。
3. Crema 加载模板，运行指令，转义回显，并通过 `toResponse()` 返回 HTML。

## 脚手架

`kona new`（默认 **web** 套件）已经登记 `CremaServiceProvider` 并带有欢迎视图。用 grind 添加更多模板：

```bash
./grind make:view home
./grind make:view posts.show
```

这会创建 `src/main/resources/views/home.crema.html` 和 `src/main/resources/views/posts/show.crema.html`。

## 最小模板

```crema
{{-- src/main/resources/views/home.crema.html --}}
<h1>Hello {{ name }}</h1>
```

`{{ name }}` 打印数据映射里的 `name` 条目，并做 HTML 转义。缺少或 null 的值变成空字符串。

## 从控制器渲染

登记 `CremaServiceProvider`（web 脚手架会这样做）并启动应用。然后使用视图辅助方法：

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
import org.konaframework.crema.view
import org.konaframework.http.Request
import org.konaframework.http.Response

class WelcomeController {
    fun index(request: Request): Response =
        view("welcome", mapOf("name" to "Kona")).toResponse()
}
```

</TabItem>
<TabItem label="Java">

```java
import org.konaframework.crema.Views;
import org.konaframework.http.Request;
import org.konaframework.http.Response;
import java.util.Map;

public final class WelcomeController {
    public Response index(Request request) {
        return Views.make("welcome", Map.of("name", "Kona")).toResponse();
    }
}
```

</TabItem>
</Tabs>

完整的工厂 API（share、`first`、存在性、Java/Kotlin 表）：[视图辅助方法](/docs/crema/view-helper/)。

## 视图路径与配置

| 设置 | 行为 |
|------|------|
| 默认根 | `{basePath}/src/main/resources/views` |
| 回退 | `build/resources/main/views`，然后是旧的 `resources/views` |
| 覆盖 | 配置键 `view.path`（绝对路径或相对应用的路径） |

点分名变成路径段：`mail.orders.shipped` → `mail/orders/shipped.crema.html`。Crema 先尝试 `.crema.html`，再尝试 `.crema.kt`。

## 引擎查找的数据

有些指令从同一份数据映射（或子上下文）读取约定键。你从控制器或中间件传入它们：

| 键 | 使用者 |
|----|--------|
| `_token` / `csrf_token` | `@csrf` |
| `asset_url` / `assetUrl` | `@asset` 基前缀 |
| `__authenticated`、`auth_user`、`user` | `@auth` / `@guest` |
| `__abilities` 或 `can` | `@can` / `@cannot` |
| `errors` | `@error('field')` |
| `lang` | `Lang.get` 之前的 `@lang` 覆盖 |

## 指令菜单

| 区域 | 指令 |
|------|------|
| 回显 | `{{ }}`、`{!! !!}`、`@@`、`{{-- --}}` |
| 布局 | `@extends`、`@section` / `@endsection` / `@show`、`@yield`、`@parent`、`@hasSection`、`@sectionMissing` |
| 栈 | `@push` / `@endpush`、`@prepend` / `@endprepend`、`@stack` |
| 包含 | `@include`、`@includeIf`、`@includeWhen`、`@includeUnless`、`@includeFirst`、`@once`、`@verbatim` |
| 条件 | `@if` / `@elseif` / `@else` / `@endif`、`@unless`、`@isset`、`@empty` |
| 循环 | `@while`、`@foreach` / `@each` / `@for`、`@forelse`、`loop.*` |
| 认证 | `@auth`、`@guest`、`@can`、`@cannot` |
| 分支 | `@switch` / `@case` / `@break` / `@default` / `@endswitch` |
| 组件 | `@component` / `@slot`、`<x-*>`、`<x-slot>` |
| 辅助 | `@json`、`@csrf`、`@method`、`@asset`、`@lang`、`@vite`、`@error` |

完整表格：[指令参考](/docs/crema/directives/)。
