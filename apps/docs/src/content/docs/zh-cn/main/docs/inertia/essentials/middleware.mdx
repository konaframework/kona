`HandleInertiaRequests`（类型别名 `InertiaMiddleware`）应放在 HTTP 内核上，覆盖全部 Inertia 路由。

## 生命周期

1. 解析 `Inertia.manager()`（需要已启动的 `InertiaServiceProvider`）
2. `setRequest(request)`
3. 应用 `share(request)` → `shareForRequest`
4. 可选的 `version(request)` → 更新 `manager.version`
5. 如果 `versionConflict(request)` → 返回装饰后的 `409`
6. 否则 `decorate(next.handle(request))`
7. `finally` → `setRequest(null)`（清掉本次请求范围的共享属性）

## 覆盖

| 方法 | 默认 | 用途 |
|------|------|------|
| `share(request)` | 空映射 | 每次请求的属性 |
| `version(request)` | `null`（保留管理器版本） | 动态资源版本 |

## 注册

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.resolve(HttpKernel::class.java).pushMiddleware(HandleInertia())
// or alias via HttpMiddleware if you use the web stack
```

</TabItem>
<TabItem label="Java">

```java
app.resolve(HttpKernel.class).pushMiddleware(new HandleInertia());
```

</TabItem>
</Tabs>

在 `InertiaServiceProvider` 已经启动之后再压入中间件，这样门面上的管理器才已设置。
