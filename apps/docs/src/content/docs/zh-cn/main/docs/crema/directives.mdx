Crema 语法的快速查找。解释和完整示例请顺着“指南”链接阅读。

## 回显与注释

| 语法 | 用途 | 指南 |
|------|------|------|
| `{{ expr }}` | 转义输出 | [渲染](/docs/crema/rendering/) |
| `{!! expr !!}` | 原始 HTML 输出 | [渲染](/docs/crema/rendering/) |
| `{{ url(path) }}` / `{{ route(name) }}` / `{{ asset(path) }}` | 应用 / 具名 / 公开 URL | [渲染](/docs/crema/rendering/#echo-helpers) |
| `{{ csrf_token() }}` / `{{ old(key) }}` | CSRF 令牌 / 闪存输入 | [渲染](/docs/crema/rendering/#echo-helpers) |
| `{{ env(key) }}` / `{{ config(key) }}` | 环境 / 配置 | [渲染](/docs/crema/rendering/#echo-helpers) |
| `{{ trans(key) }}` / `{{ __(key) }}` / `{{ lang(key) }}` | 翻译 | [渲染](/docs/crema/rendering/#echo-helpers) |
| `@@` | 字面量 `@` | [渲染](/docs/crema/rendering/) |
| `{{-- … --}}` | 注释（会被去掉） | [渲染](/docs/crema/rendering/) |

## 布局与节

| 指令 | 结束 / 说明 | 指南 |
|------|-------------|------|
| `@extends('layout')` | 子视图声明父布局 | [布局](/docs/crema/layouts/) |
| `@section('name', 'text')` | 内联节 | [布局](/docs/crema/layouts/) |
| `@section('name')` | 块节 | `@endsection` 或 `@show` |
| `@endsection` | 结束块节（按原文存储） | [布局](/docs/crema/layouts/) |
| `@show` | 结束节并立即展开 | [布局](/docs/crema/layouts/) |
| `@yield('name')` | 打印节 | 可选默认值：`@yield('n', 'default')` |
| `@parent` | 插入父节缓冲 | 在子级 `@section` 内部 |
| `@hasSection('name')` | 节已定义时的正文 | 用 `@endif` 结束 |
| `@sectionMissing('name')` | 节缺失时的正文 | 用 `@endif` 结束 |

## 包含与原始区域

| 指令 | 说明 | 指南 |
|------|------|------|
| `@include('name')` | 必需；缺少时抛出 | [包含](/docs/crema/includes/) |

| `@includeWhen(expr, 'name')` | 为真时 | [包含](/docs/crema/includes/) |
| `@includeUnless(expr, 'name')` | 不为真时 | [包含](/docs/crema/includes/) |
| `@includeFirst(['a', 'b'])` | 第一个能解析的名称 | [包含](/docs/crema/includes/) |
| `@once` | `@endonce` — 每次渲染一次 | [包含](/docs/crema/includes/) |
| `@verbatim` | `@endverbatim` — 不处理 | [包含](/docs/crema/includes/) |

## 循环

| 指令 | 结束 | 说明 | 指南 |
|------|------|------|------|
| `@foreach(items as item)` | `@endforeach` | 也支持 `as key => value` | [控制结构](/docs/crema/control-structures/) |
| `@each(items as item)` | `@endeach` | foreach 的别名 | [控制结构](/docs/crema/control-structures/) |
| `@for(…)` | `@endfor` | 集合、`i in a..b` 或 C 风格 | [控制结构](/docs/crema/control-structures/) |
| `@forelse(items as item)` | `@endforelse` | 需要 `@empty` 分支 | [控制结构](/docs/crema/control-structures/) |

### `loop` 键

`index`、`iteration`、`first`、`last`、`count`、`remaining`、`even`、`odd`、`depth`、`parent` — 见[循环元数据](/docs/crema/control-structures/#loop-metadata)。

## 组件与插槽

| 语法 | 用途 | 指南 |
|------|------|------|
| `@component('name')…@endcomponent` | 把视图渲染成组件 | [组件](/docs/crema/components/) |
| `@slot('name')…@endslot` | `@component` 内的具名插槽 | [组件](/docs/crema/components/) |
| `<x-name>…</x-name>` | 渲染 `components.name` | [组件](/docs/crema/components/) |
| `<x-name />` | 空的默认插槽 | [组件](/docs/crema/components/) |
| `<x-slot name="n">…</x-slot>` | `<x-*>` 或带前缀标签的具名插槽 | [组件](/docs/crema/components/) |
| `<x-slot:n>…</x-slot:n>` | 冒号名形式 | [组件](/docs/crema/components/) |
| `<prefix:slot name="n">…` | 扩展标签的具名插槽 | [组件](/docs/crema/components/) |

在组件视图内部：`{{ slot }}`（默认）以及每个具名插槽的 `{{ name }}`。

## 自定义扩展

应用和包可以在 `CremaEngine` 上登记更多语法：

| API | 形状 |
|-----|------|
| `directive(name) { … }` | `@name` / `@name(args)` |
| `blockDirective(name) { … }` | `@name…@endname` |
| `tag(prefix) { … }` | `<prefix:name>…` |

Wire 用这些实现 `@brew` 和 `<wire:…>`。见 [Wire](/docs/wire/)。
