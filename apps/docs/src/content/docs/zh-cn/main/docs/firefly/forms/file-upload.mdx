`FileUpload` renders a FilePond drop area. Dropped files go to `POST /_firefly/uploads`; the returned path is stored in a hidden input that posts with the form.

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
FileUpload.make("avatar")
    .label("Avatar")
    .avatar()
    .disk("local")
    .directory("avatars")
    .maxSize(2048)
```

</TabItem>
<TabItem label="Java">

```java
FileUpload.make("avatar")
    .label("Avatar")
    .avatar()
    .disk("local")
    .directory("avatars")

```

</TabItem>
</Tabs>

## Storage and commit

Temporary files land under `firefly-temporary/`. Call `commit(schema, disks)` to copy (or move) into `directory()`, apply naming, visibility, and size / type checks.

| Method | Effect |
|--------|--------|
| `disk` / `directory` / `visibility` | Target filesystem |
| `multiple` / `maxFiles` / `minFiles` | Multi-file constraints |
| `acceptedFileTypes(...)` | `image/*`, mime, `.png`, or extension |
| `maxSize` / `minSize` | Kilobytes |
| `image()` / `avatar()` | Image accept + avatar editor defaults |
| `imageEditor` / aspect / mode / viewport / fill | Editor chrome |
| `imagePreviewHeight` / resize / crop / upscale / EXIF | Image processing flags |
| `downloadable` / `openable` / `previewable` / `reorderable` | File actions |
| `appendFiles` / `storeFiles` / `moveFiles` / `preserveFilenames` | Persist behavior |
| `preventFilePathTampering` | Reject `..`, absolute, `.ffmeta`, out-of-dir paths |
| `pasteable` / `fetchFileInformation` / `maxParallelUploads` | UX |
| `panelLayout` / `panelAspectRatio` / button & progress positions | Layout |
| `uploadingMessage` / `storeFileNamesIn` | Copy / sidecar state |
| `browseAction` / `browse` / `chooseBrowsed` | Pick existing files |
| `getUploadedFileNameForStorageUsing` | Custom stored name |

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
FileUpload.make("docs")
    .multiple(true)
    .acceptedFileTypes("application/pdf", ".docx")
    .maxFiles(5)
    .storeFileNamesIn("docNames")
    .moveFiles(true)
```

</TabItem>

## Validation

Required empty uploads and tampered paths surface through `extraErrors`. Mount CSRF protection on the upload route; the field script sends `X-CSRF-TOKEN` and `_token`.
