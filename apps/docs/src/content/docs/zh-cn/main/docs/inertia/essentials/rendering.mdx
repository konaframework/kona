## 门面 API

| 调用 | 行为 |
|------|------|
| `Inertia.render(component)` | 属性为空；使用中间件里的当前请求 |
| `Inertia.render(component, props)` | 同上，并带属性映射 |
| `Inertia.render(request, component)` | 显式请求 |
| `Inertia.render(request, component, props)` | 显式请求加属性 |

没有中间件（或 `manager.setRequest`）时，省略 `request` 的调用会抛出 `InertiaException`。

<TabItem label="Kotlin">

```kotlin
Inertia.render("Pages/Users/Index", mapOf(
    "users" to listOf(mapOf("id" to 1, "name" to "Ada")),
))
```

<TabItem label="Java">

Inertia.render("Pages/Users/Index", Map.of(
    "users", List.of(Map.of("id", 1, "name", "Ada"))

## 页面对象

序列化到 JSON / `data-page` 的 `InertiaPage` 字段：

| 字段 | 含义 |
|------|------|
| `component` | 客户端组件名（例如 `Pages/Home`） |
| `props` | 合并后的共享属性、请求共享属性和本地属性 |
| `url` | `request.path` |
| `version` | 管理器版本；为空时是 `null` |

属性合并顺序：**全局共享** → **每次请求的共享**（中间件）→ **本地属性**（键冲突时胜出）。

## 组件命名

`component` 字符串对 Kona 是不透明的 — 它原样传给客户端。按惯例，套件和 `./grind install` 脚手架使用 `Pages/Name`，并解析 `src/main/resources/js/Pages/Name.{vue,jsx,svelte}` 下的文件。服务器和客户端的命名要保持一致，否则浏览器会报找不到页面。

## 何时选择 HTML 或 JSON

| 条件 | 正文 |
|------|------|
| 没有 `X-Inertia` 请求头 | 带 `data-page` 的 HTML 根外壳（`root_view` / `root_html`） |
| `X-Inertia: true` 且版本正确 | JSON 页面对象 |
| `X-Inertia: true` 且版本不匹配 | `409`（见[资源版本](../../advanced/versioning/)） |

你不在控制器里选择模式 — 两种情况都以同样的方式调用 `Inertia.render`；中间件和管理器选择表示形式。

## 惰性 / 缺少请求

```kotlin
// Throws if middleware has not set the current request:
Inertia.render("Pages/Home")

// Explicit request (tests, unusual pipelines):
Inertia.render(request, "Pages/Home", mapOf("ok" to true))
```
