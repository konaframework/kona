`Repeater` edits a list of maps. Each item uses the same field blueprint. The field posts one JSON array under its name.

<FireflyShot file="form-repeater.png" description="Repeater notes field on the Playground form." />

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
Repeater.make("notes")
    .label("Notes")
    .schema(
        TextInput.make("title").label("Title").required(),
        Textarea.make("body").label("Body"),
    )
    .addable(true)
    .reorderable(true)
    .cloneable(true)
    .collapsible(true)
    .minItems(1)
    .maxItems(10)
    .defaultItems(1)
    .addActionLabel("Add note")
```

</TabItem>

`simple(field)` is a shortcut for a single-field schema.

## Options

| Method | Effect |
|--------|--------|
| `schema(...)` / `simple(field)` | Item blueprint |
| `addable` / `deletable` / `reorderable` / `cloneable` | Item controls |
| `collapsible` / `collapsed` | Collapse chrome |
| `grid(count)` | Columns inside each item |
| `minItems` / `maxItems` / `defaultItems` | Counts |
| `orderColumn` | Write 1-based sort positions |
| `relationship(name)` | Store relation name (does not load records alone) |
| `itemLabel` | Fixed label or `(index, Get) -> String` |
| `addActionLabel` | Add button copy |
| `addAction` / `deleteAction` / `cloneAction` / `extraItemActions` | Extra `Action`s |
| `items` / `addItem` / `removeItem` / `cloneItem` / `moveItem` | Mutate schema state |

Child fields marked `distinct()` reject duplicate values across items. Required children are checked in `extraErrors`.
