`ImageColumn` reads a URL string from the row and renders `<img class="ff-image">`. An empty source renders an empty column shell.

<FireflyShot file="column-image.png" description="An image column showing avatar thumbnails." />

## Size and alt

`alt(...)` sets the accessibility text (string or `Function<Cell, String>`). `imageHeight(pixels)` and `imageWidth(pixels)` set integer pixel attributes on the tag.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
ImageColumn.make("avatar")
    .label("Photo")
    .alt { cell -> cell.get("name")?.toString() ?: "Avatar" }
    .imageHeight(40)
    .imageWidth(40)
```

</TabItem>
<TabItem label="Java">

```java
ImageColumn.make("avatar")
    .label("Photo")
    .alt(cell -> {
        Object name = cell.get("name");
        return name == null ? "Avatar" : name.toString();
    })
    .imageHeight(40)
    .imageWidth(40);
```

</TabItem>
</Tabs>
