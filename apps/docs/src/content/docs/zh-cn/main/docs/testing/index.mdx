**kona-testing** 是 Kona 应用的测试工具。它在临时基路径下启动一个真实的 `Application`，然后驱动 HTTP、grind、数据库和内存伪造对象，而不打开套接字或碰生产服务。

把它加为测试依赖：

```kotlin
dependencies {
    testImplementation("org.konaframework:kona-testing:${konaVersion}")
}
```

## 启动应用

`TestApplication.create(base, *providers)` 是 `Kona.create("--base=…").providers(…).boot()` 的薄包装。

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
@TempDir
lateinit var base: Path

val app = TestApplication.create(
    base,
    HttpServiceProvider(),
    MyAppProvider(),
)
```

</TabItem>
<TabItem label="Java">

```java
Path base = Files.createTempDirectory("app");
Application app = TestApplication.create(
    base,
    new HttpServiceProvider(),
    new MyAppProvider()
);
```

</TabItem>
</Tabs>

在你传入的提供者里（或启动之后）登记路由、绑定和中间件。清理通常就是“丢掉临时目录” — 优先用新的基路径，而不是在测试之间复用长期应用。
