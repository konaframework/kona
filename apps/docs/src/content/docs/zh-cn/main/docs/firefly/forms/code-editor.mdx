`CodeEditor` is a plaintext editor with a highlighted layer under the textarea. It is not a rich-text surface.

<FireflyShot file="form-code-editor.png" description="CodeEditor snippet field on the Playground form." />

## Add the field

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
CodeEditor.make("snippet")
    .label("Snippet")
    .language("kotlin")
    .wrap(true)
```

</TabItem>
<TabItem label="Java">

```java
CodeEditor.make("snippet")
    .label("Snippet")
    .language("kotlin")
    .wrap(true);
```

</TabItem>
</Tabs>

## Options

| Method | Effect |
|--------|--------|
| `language(value)` | Grammar id (non-blank) |
| `language()` | Current language |
| `wrap()` / `wrap(on)` | Soft wrap |
| `CodeEditor.languages()` | Ids shipped with the module |

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val langs = CodeEditor.languages()
```

</TabItem>
<TabItem label="Java">

```java
List<String> langs = CodeEditor.languages();
```

</TabItem>
</Tabs>
